Abstract. Multilingual automatic speech recognition (ASR) has achieved rapid progress with large-scale pretrained models and multilingual speech corpora. Previous studies have proved the pivotal role of data sampling in multilingual ASR performance. However, existing sampling strategies largely rely on time-consuming manual, heuristic-based designs. To ad-dress this, we propose a linguistic-aware agentic data sampling framework that introduces a data sampling LLM agent into the multilingual ASR training loop. The agent is driven by a linguistically grounded rubric that analyzes ASR errors from phonological, morphological, and syntactic per-spectives, and uses the resulting feedback together with training statis-tics, budget constraints, and algorithm profiles to select domain-level, sample-level, and token-level sampling strategies. This design turns eval-uation results into adaptive data-selection decisions rather than treating WER/CER as final endpoints only. We conduct experiments on twelve Common Voice languages using Whisper-medium as the ASR backbone. The results show that our method achieves performance better than full-data training while using less training data and lower computational re-sources, and substantially accelerates training convergence compared to conventional sampling strategies. 

Keywords: Multilingual ASR · Agentic Data Sampling · Linguistic Er-ror Analysis 

## 1 Introduction 

Multilingual automatic speech recognition (ASR) aims to recognize multiple languages within a unified model, reducing the cost of developing and main-taining language-specific systems. Large-scale joint training has demonstrated

the value of cross-lingual parameter sharing, particularly for low-resource lan-guages [1]. Cross-lingual self-supervised pretraining, weakly supervised sequence-to-sequence learning, and massively multilingual scaling have further extended language coverage and transferability [2–4]. Despite this progress, recognition performance remains uneven across languages because multilingual corpora dif-fer substantially in data availability, acoustic conditions, pronunciation systems, morphology, and writing conventions. A central challenge is therefore how to use heterogeneous multilingual train-ing data effectively under a limited budget. Existing approaches typically con-catenate corpora, balance languages, follow predefined curricula, or select aux-iliary data according to corpus relatedness, historical feedback, or acoustic and phonetic similarity [5–8]. These methods demonstrate that multilingual data are not equally useful. However, most optimize a predefined criterion at a sin-gle granularity, such as language weighting or utterance selection. They do not jointly adapt language allocation, utterance selection, and token supervision to the model’s evolving error profile. Current evaluation practice provides limited support for such adaptation. Multilingual benchmarks commonly report average and per-language WER/CER [9]. Although essential for system comparison, these metrics are affected by tokeniza-tion, writing systems, morphology, and normalization [10, 11], and do not iden-tify the linguistic source of an error. Typological studies show that phonological, morphological, and syntactic properties help explain cross-language performance differences [12]. Nevertheless, such analyses are generally performed after train-ing and are rarely converted into decisions about what data the model should learn from next. This leaves a gap between multilingual ASR error diagnosis and data optimization. In this work, we propose a linguistic-aware agentic data sampling framework that closes this loop. After each training round, recognition outputs are analyzed through a linguistic rubric covering phonology, morphology, and syntax. An LLM agent combines these diagnostics with per-language performance, training his-tory, budget constraints, and algorithm profiles. It then produces an executable sampling plan consisting of domain-, sample-, and token-level algorithm choices and their parameters for the next round. Data sampling is thus formulated as an adaptive, feedback-driven process rather than a fixed preprocessing strategy. Our contributions are threefold. First, we formulate multilingual ASR data sampling as a closed-loop optimization problem in which evaluation results di-rectly guide subsequent training-data selection. Second, we provide a linguistic error rubric and a hierarchical agentic sampler that coordinate language allo-cation, utterance selection, and token-level supervision according to the current model state. Third, extensive experiments on twelve Common Voice languages show that the proposed method outperforms both no-sampling and random-sampling baselines in average multilingual recognition performance under the same cumulative training budget, while achieving the best results on most eval-uated languages. ## 2 Related Works 

2.1 Evaluation and Error Diagnosis in Multilingual ASR 

Multilingual ASR evaluation has developed from testing individual languages on separate corpora toward broader and more standardized cross-lingual bench-marks. Common Voice provides diverse community-contributed speech across many resource conditions, while FLEURS enables more controlled comparison through parallel content across languages [13, 14]. XTREME-S and the ML-SUPERB series further evaluate multilingual speech representations across lan-guages, datasets, adaptation settings, and related speech tasks [9, 15, 16]. Re-cent extensions additionally consider language varieties, accents, dialects, code-switching, and long-form recognition [17–19]. These benchmarks have made per-language performance and cross-lingual robustness increasingly visible, rather than relying only on a single macro-average score. Despite this broader coverage, multilingual ASR is still evaluated primarily with WER and CER. These metrics provide reproducible measures of transcrip-tion accuracy, but their interpretation varies with writing systems, tokeniza-tion conventions, word boundaries, and morphological structure. CER can offer greater consistency than WER for some multilingual comparisons, but neither metric identifies the linguistic source of an error [10]. Reported results are also sensitive to evaluation design: language-insensitive normalization may remove meaningful orthographic information, while annotation and language-label in-consistencies in multilingual corpora can distort the measured performance [11, 20]. This limitation is important because similar WER/CER values may reflect different model weaknesses. Errors may arise from phone confusions and phono-tactic patterns, missing inflectional markers, or incorrectly recognized function words. Typologically informed analyses have shown that phonological, morpho-logical, and syntactic properties help explain cross-language performance vari-ation in multilingual ASR systems [12]. Such analyses therefore offer a more informative view of model behavior than aggregate edit distance alone. However, existing evaluation and diagnostic studies are mainly used for bench-marking or post-hoc interpretation. They reveal which languages or linguistic properties are difficult, but usually do not determine how the training data should be changed in response. This leaves a gap between error diagnosis and model optimization. Our work addresses this gap by converting phonological, morphological, and syntactic error statistics into structured feedback for subse-quent domain-, sample-, and token-level data selection. In this way, multilingual evaluation is used not only to measure the final model, but also to guide the next training round. 4 Z. Qian et al. 

2.2 Data Sampling Algorithms 

Data sampling and selection improve training efficiency by assigning different importance to data sources, examples, or supervision units. At the domain level, DoReMi learns mixtures of heterogeneous data sources using proxy-model ex-cess losses and distributionally robust optimization [21]. DoGE estimates the contribution of each domain to target generalization through bilevel optimiza-tion and gradient-based signals [22], while exponentiated-gradient reweighting provides a general mechanism for converting domain scores into adaptive sam-pling distributions [23]. These methods show that a fixed data mixture may become suboptimal as training progresses. Finer-grained methods operate on individual examples or tokens. LESS uses low-dimensional gradient representations to select examples that align with a target or validation objective [24]. RHO-1 prioritizes under-learned tokens ac-cording to their excess loss relative to a reference model [25], whereas TOSS uses token-level risk signals to suppress undesirable supervision [26]. Although these methods were mainly developed for language-model training, they estab-lish complementary mechanisms for domain reweighting, example selection, and token-level control. Multilingual ASR introduces additional selection criteria because the value of speech data depends on both linguistic and acoustic relationships. Corpus-relatedness sampling selects auxiliary speech according to source–target similar-ity [5], while adversarial meta-sampling adapts language selection using historical model feedback [6]. Other approaches use phoneme overlap and pronunciation information for dynamic multilingual sampling [7], or estimate positive cross-lingual transfer through acoustic pseudo-tokens and clip-level acoustic similar-ity [8, 27]. These findings show that data quantity or loss alone cannot fully determine the usefulness of multilingual speech. Beyond multilingual ASR, recent studies have investigated the use of LLMs and agentic mechanisms for data selection and preparation. AskLLM leverages the zero-shot reasoning capability of an instruction-tuned LLM to directly as-sess the quality of individual training examples, demonstrating that LLM-based semantic judgments can serve as effective data-selection signals [28]. Bai et al. in-troduce a multi-actor collaborative framework in which multiple data-selection strategies independently prioritize samples and a central console dynamically combines their decisions according to the current training state [29]. Moving beyond sample scoring, DataFlow introduces an LLM-driven agent that trans-lates natural-language data requirements into executable preparation pipelines composed of generation, evaluation, filtering, and refinement operators [30]. These agentic data sampling method has not been adapted to multilingual ASR. Existing approaches, however, generally employ a predefined selection cri-terion and operate at one granularity, such as language weighting or utterance selection. Coordinating language-level allocation, utterance-level relevance, and token-level supervision according to changing multilingual ASR errors remains comparatively underexplored[31]. ## 3 Method 

We propose a linguistic-aware agentic data sampling framework. The system use an LLM-based agent to drive the data sampling process to train a multi-lingual ASR model. The overall pipeline is shown in Fig. 1. In summary, the agentic workflow proceeds as an iterative training loop. At each epoch, the system first samples a batch from the training corpus and uses it to fine-tune the ASR model. The fine-tuned model is then evaluated on the development set, and its recognition outputs are converted into a linguistic rubric report. Based on this report together with the training statistics, the LLM agent designs a three-stage data-sampling plan covering domain-level, sample-level, and token-level decisions. This plan is then applied to the training corpus to construct the subset used for fine-tuning in the next epoch. 

3.1 Linguistic Rubric 

We propose a linguistic rubric for our multilingual ASR data sampling agent, which converts raw ASR recognition errors into more detailed statistics from a linguistic perspective, and provides structured feedback for data sampling. The rubric attributes some ASR errors into three linguistic dimensions: phonology, 6 Z. Qian et al. 

morphology, and syntax. The goal of the rubric is not to replace WER or CER, but to explain which linguistic phenomena contribute to the observed errors. Based on the detailed error distribution in each linguistic dimension, the agent can identify more specific weaknesses and select more targeted sampling strate-gies. 

Phonology. The phonology dimension analyzes ASR errors at the phoneme level. We convert grapheme-level references and predictions into IPA representations using eSpeak NG [32], and then identify errors at the granularity of uniphones, biphones, and triphones. This dimension helps identify which sounds or sound combinations are difficult for the model and supports phone-aware sample selec-tion. 

Morphology. The morphology dimension focuses on word-formation errors, es-pecially inflectional errors and case, gender, number, or tense marker errors. We compare aligned reference and hypothesis tokens to determine whether the main lexical stem is preserved while a morphological marker changes or disappears. In morphologically rich languages, a single inflectional error can alter the gram-matical or semantic function of a word while causing only a minimal change in character-level edit distance. 

Syntax. The syntax dimension focuses on errors involving prepositions, func-tion words, and local word-order patterns. Although ASR is an acoustic-to-text task, recognition errors often appear as systematic textual mistakes, such as dropped function words or confused short grammatical words. Syntax-level anal-ysis therefore provides additional guidance for selecting utterances that contain error-prone grammatical contexts. For each linguistics dimension, the rubric report contains both categorical distribution and short natural-language summaries. The report is then passed to the agent together with WER/CER and training statistics. In this way, the agent can distinguish, for example, a language whose high WER is mainly caused by phoneme confusions from another language whose errors are dominated by inflectional endings or function words.

## 4 Experiments 

4.1 Setup Dataset We employ a 12-language subset of Common Voice [13] as our bench-mark, covering Belarusian (be), Chinese (zh), Dutch (nl), French (fr), German (de), Italian (it), Japanese (ja), Polish (pl), Portuguese (pt), Russian (ru), Span-ish (es), and Turkish (tr). This subset comprises a training corpus, a development set, and a test set. Both the development and test sets are 12 hours, equally dis-tributed with exactly one hour per language. The training corpus comprises a total duration of 600 hours, with each language contributing an equal share of 50 hours. 

Baselines and Implementation We fine-tune the Whisper-medium [3] model on this dataset using various data sampling strategies to evaluate their impact on automatic speech recognition (ASR) performance. To isolate the effects of the sampling strategies, all methods are assessed under identical model architectures, optimizer configurations, and evaluation protocols. Specifically, we employ Low-Rank Adaptation [33] with a rank r = 64 , α = 64 , and a dropout rate of 0.05. The model is optimized using the AdamW optimizer with a learning rate of 

1 × 10 −4 and a per-device batch size of 128, distributed across 8 Ascend 910B NPUs. To ensure a fair comparison, the total duration of trained data for all mod-els is strictly fixed at 1,200 hours. We benchmark our proposed agentic data sampling method against two baselines: a no-sampling baseline and a random sampling baseline. The no-sampling baseline utilizes the complete training corpus without any selection strategy; specifically, it was trained on the full 600-hour data for 2 epochs. The random sampling method involves randomly selecting 300 hours of data from the training corpus, repeated over 4 iterations. For our agentic sampling method, we evaluated different sampling durations, extracting batches of 100 and 300 hours of data from the training corpus respectively to reach the target training volume. Consequently, the agentic system performs 12 and 4 sampling iterations respectively.

## 5 Analysis 

5.1 Agent Decision Behavior 

We further examine whether the sampling policy produced by the agent is adap-tive and interpretable rather than equivalent to a fixed schedule. At each round, the agent receives the evaluation history and linguistic error diagnostics from the preceding round, and jointly selects domain-, sample-, and token-level sampling strategies for the next round. Table 4 shows a transition from a conservative cold-start policy to diagnosis-conditioned decisions. In the first round, no previous evaluation history is avail-able, so the agent selects broadly applicable loss-based methods rather than making language- or error-specific interventions. Once diagnostic feedback be-comes available, the selected actions change across rounds instead of repeating the initial configuration. This behavior indicates that the policy is conditioned on the evolving error profile of the ASR model rather than following a predefined sampling schedule. 5.2 Linguistic Error Reduction 

Beyond aggregate WER/CER, we further examine whether agentic data sam-pling reduces linguistically meaningful recognition errors. We compare the origi-nal Whisper-medium model with the model obtained after four epochs of agentic data sampling. Both models are evaluated on the same Common Voice test set covering 12 languages. For phonological analysis, we convert each reference and hypothesis into IPA phone sequences using G2P, strip non-phonemic markers, and count all mismatched 1-, 2-, and 3-phone n-gram events over the full test set. For morphology and syntax, we use rule-based detectors for inflectional marker errors, preposition/function-word errors, and word-order deviations. Table 5 reveals a complementary pattern across linguistic levels. Phonological errors contribute the largest absolute reductions, reflecting their high frequency in multilingual ASR, while morphological errors exhibit the largest relative im-provement. This suggests that the benefit of agentic data sampling is not con-fined to frequent acoustic–phonetic confusions: it also extends to less frequent but linguistically informative errors, such as inflectional suffixes and word-final grammatical markers. The consistent reductions from uniphone to triphone er-rors further indicate improved modeling of both individual phonemes and short phonetic contexts, although the smaller gain at higher n-gram orders suggests that longer context-dependent confusions remain more difficult. These results support the central motivation of our agentic sampling frame-work. A uniform sampling strategy treats all training data as equally useful, whereas the agent adjusts the data distribution using historical model perfor-mance and linguistic error feedback. The observed error profile is consistent with the agent allocating additional training exposure to languages or samples con-taining persistent phonological contrasts, morphologically marked word forms, and grammatical function words. In particular, the substantial reduction in mor-phological errors suggests that adaptive sampling can improve phenomena that may be underrepresented in the overall training distribution and therefore re-ceive insufficient attention under uniform sampling. The reduction in preposition and function-word errors also indicates that the improvement is not limited to content-word recognition, but extends to local grammatical information. However, the number of word-order deviations is too small to draw a reliable conclusion about global syntactic modeling. Overall, the linguistic breakdown provides evidence that agentic data sampling changes not only the aggregate error rate but also the composition of the remaining errors, yielding improvements across acoustic–phonetic and grammatical dimen-sions that cannot be fully characterized by WER/CER alone. 

## 6 Conclusion 

We proposed a linguistic-aware agentic data sampling framework for multilingual ASR that converts phonological, morphological, and syntactic error diagnostics into domain-, utterance-, and token-level sampling decisions. By placing evalua-tion inside the training loop, the framework treats data sampling as an adaptive process rather than a fixed preprocessing strategy. Experiments on twelve Common Voice languages with Whisper-medium show that the agentic-300h setting achieves an average error rate of 19.4, compared with 23.9 for no sampling and 22.5 for random sampling, and obtains the best result on nine languages. The method also reduces phone-level, inflectional, and function-word errors, while the selected strategies change with the evolv-ing model error profile. These results suggest that multilingual ASR evaluation can serve not only to measure performance, but also to provide actionable feed-back for subsequent data selection. Future work will extend the framework to broader language coverage and conduct finer-grained ablations of the linguistic rubric and individual sampling decisions. 14 Z. Qian et al.

You are a data sampling agent for multilingual ASR training. ## Context The pipeline runs three stages sequentially: domain (= language) -> sample (= utterance) -> token (= subword) Each stage's output feeds into the next. ## Current stage You are configuring **Stage {stage_num} -- {stage_name} ({stage_level})**. Available algorithms: {available_algorithms} This stage runs **{stage_phase}**. ## What you will receive - ``rubric_diagnosis``: error patterns, per-language CER, overall CER, phone/grapheme distributions, and summary text. - ``previous_stages``: summary of what earlier stages did and their results. (empty for the first stage) - ``selection_context``: experiment-level constraints and cross-epoch algorithm usage history, including under-used algorithms and recent domain->sample->token paths. ## Rules 1. Choose exactly ONE algorithm from the available list. 2. Set specific parameter values using the parameter schemas below. 3. Prefer conservative settings unless the diagnosis clearly supports aggressive filtering. 4. This experiment must explore the algorithm pool across epochs. Prefer under-used algorithms and new stage combinations when their required inputs are available from the rubric or from orchestrator precompute. If an algorithm has zero or much lower usage than the alternatives at the same stage, choose it before reusing a heavily repeated stage algorithm unless it is invalid for the current inputs. Avoid repeating the same stage algorithm for more than two consecutive epochs unless every alternative is invalid; if you repeat, explain why. 5. Do not choose an algorithm only because it was used in the previous epoch. Balance current diagnosis fit with coverage of doremi/exp_reweight/doge, less/pe_dstb, and rho1/toss over the full run. 6. Return valid JSON matching the required schema. 7. Output schema fields following their original order in the schema (rationale -> algorithm -> params). ,→
