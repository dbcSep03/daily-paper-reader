## 摘要
自进化LLM智能体有望通过持续交互与学习实现自主改进，从而减少对手工整理监督的依赖。实现这一前景不仅需要更新智能体，还需要在其能力变化时同步演化其训练经验。然而，现有大多数流程依赖静态数据集或单独更新的合成模型，导致原本有用的任务变得过于简单，而过难的任务仍然缺乏信息量。智能体能力与训练经验之间日益加剧的失配限制了持续自我改进。为解决这一问题，我们提出SynCo，一种基于多智能体强化学习、面向自进化LLM的智能体化数据合成协同训练框架。SynCo联合优化两个独立参数化的智能体：合成器（Synthesizer）根据推理器（Reasoner）不断演进的能力状态构建训练任务，推理器则从由此产生的经验中学习。每个合成任务都会引发Reasoner的多次rollout，其结果向两个智能体提供互补奖励。正确性反馈改进Reasoner，而任务质量、答案可靠性以及以结果为依据的可教性指导Synthesizer。它们的更新会被反馈到后续合成轮次中，使任务求解策略及其训练分布能够共同演化。在八个数学推理基准上的大量实验表明，SynCo显著优于多种现有合成数据方法和受控基线，取得了最强的整体性能，且其大部分增益来自此前未解决的问题。

## Abstract
Self-evolving LLM agents promise to improve autonomously through continual interaction and learning, reducing their dependence on manually curated supervision. Realizing this promise requires not only updating the agent, but also evolving its training experience as its capabilities change. However, most existing pipelines rely on static datasets or separately updated synthesis models, causing previously useful tasks to become trivial while overly difficult tasks remain uninformative. This growing mismatch between agent capability and training experience limits sustained self-improvement. To address this problem, we propose SynCo, an agentic data synthesis co-training framework for self-evolving LLMs based on multi-agent reinforcement learning. SynCo jointly optimizes two independently parameterized agents: a Synthesizer that constructs training tasks from the Reasoner's evolving capability state, and a Reasoner that learns from the resulting experience. Each synthesized task induces multiple Reasoner rollouts whose outcomes provide complementary rewards to both agents. Correctness feedback improves the Reasoner, while task quality, answer reliability, and outcome-grounded teachability guide the Synthesizer. Their updates are fed back into subsequent synthesis rounds, allowing the task-solving policy and its training distribution to evolve together. Extensive experiments across eight mathematical reasoning benchmarks demonstrate that SynCo substantially outperforms a broad range of existing synthetic-data methods and controlled baselines, achieving the strongest overall performance while deriving most of its gains from previously unsolved problems.

## 1. 核心问题与研究动机

- **背景**：自进化 LLM 智能体被期望通过持续交互与经验积累自主提升，减少对人工标注监督的依赖。但现实中的训练管线仍普遍依赖**静态数据集**，或采用**分阶段/交替更新**的合成模型。
- **核心矛盾**：智能体能力在训练中不断变化，而训练经验的分布几乎不变，造成"能力—数据"错配：
  - 曾经有信息量的任务随能力提升变得**过于简单**（rollout 全对，梯度为零）；
  - 远超能力边界的任务**始终无信息量**（rollout 全错，同样无梯度）。
- **关键洞察**：现有"自适应数据合成"（按失败、不确定性、难度重生成/筛选/重加权）并不等于**联合优化**。合成策略与任务策略未在同一在线交互中被共同优化，数据生成仍是围绕训练的"辅助流程"，而非可学习组件。
- **中心问题**：能否把"智能体化数据合成"与"任务学习"建模为**统一的多智能体强化学习过程**，使数据合成策略与任务求解策略联合优化、共同演化？
- **问题本质**：这是一个**耦合且非平稳**的学习问题——Synthesizer 通过生成任务塑造 Reasoner 的优化景观，Reasoner 的每次更新又重定义"哪些任务还有用"。因此合成数据的价值不能仅由有效性、新颖性、名义难度等静态属性判定，必须锚定于当前 Reasoner 的**真实交互结果**。

## 2. 方法论：SynCo 框架

### 2.1 核心思想

将数据合成建模为**可训练策略**，与任务求解策略在**同一在线批次**上用 GRPO 同步更新，形成"智能体—数据"自进化闭环（合成 → 协同训练 → 自进化三轮循环）。

### 2.2 形式化设定

- 两个**独立参数化**的智能体：Synthesizer `πS(·; θS)` 生成任务；Reasoner `πR(·; θR)` 求解任务。
- 目标函数分离但耦合：
  - `JR(θR) = E[ (1/K) Σ_k r_R,t^(k) ]`（rollout 级正确性）
  - `JS(θS) = E[ r_S,t ]`（任务级效用）
  - 耦合性：`πS` 决定 `JR` 所依赖的数据分布；`πR` 的 rollout 决定 `JS` 的奖励来源。

### 2.3 能力条件化的数据合成

- **合成上下文**：`c_t = G(M_t) = (p_t, d_t, e_t)`
  - `p_t`：近期合成池及其覆盖度；`d_t`：Reasoner 经验表现与残余弱点；`e_t`：合成失败、冗余、被拒样本与欠探索区域。
- **结构化"任务卡"**：`x_t = (q_t, m_t, s*_t, a*_t)`
  - `q_t` 题面、`m_t` 教学意图与预估难度、`(s*_t, a*_t)` 参考解与最终答案。
  - **关键隔离**：Reasoner 只接收 `q_t`，元数据/参考解/答案仅用于验证与奖励计算，防止答案泄漏。
- **验证准入**：`V(x_t) = (v_t, ρ_t)`，检查 schema 合法性、题目完整性、答案一致性、输出格式、与近期任务的重复；可选**独立共识检验**（独立求解以校验参考答案）。
  - 未通过任务：不进入 Reasoner 训练，并给 Synthesizer 负反馈（奖励置 −0.5）。

### 2.4 交互驱动的多智能体协同训练

- Reasoner 对每个准入任务采样 `K` 条独立轨迹，`z^(k) = Check(â^(k), a*)`，`μ_t = (1/K) Σ z^(k)` 为经验成功率。
- **Reasoner 奖励**：格式正确且答对 1.0；答对但格式不符 0.9；否则 0；另加 0.1 非空输出常数奖励。
- **Synthesizer 奖励（门控式）**：
  - `r_S,t = G_q(r_quality) · G_r(r_reliability) · T(μ_t)`
  - 门函数 `G(v) = clip((v − 0.5)/0.5, 0, 1)`
  - **可教性** `T(μ) = 2μ (μ ≤ 0.5)；2(1−μ) (μ > 0.5)`，在 `μ = 0.5` 处最大，向"全对/全错"两端衰减。
  - 语义：质量与可靠性**约束可行合成空间**，Reasoner 的真实行为决定**哪个合法任务最有学习价值**。
- **联合更新**：同一在线批次 `B_t` 产生两套 group-relative 目标，`θR` 与 `θS` 在同一迭代内分别更新（参数与奖励分离，但优化问题耦合）。

### 2.5 闭环自进化

- 记忆更新：`M_{t+1} = Update(M_t, B_t)`，`c_{t+1} = G(Recent(M_{t+1}))`。
- 下一轮分布 `D̃_{t+1} = {x ~ πS(·|c_{t+1}; θS^{t+1}) | V(x).v = 1}`——同时因**上下文更新**和**合成策略更新**而改变。
- 强调：这不是"用新提示查询固定生成器"，而是**状态条件 + 生成策略**双双自适应。

## 3. 实验设计

- **Benchmark（8 个数学推理基准）**：
  - 基础：GSM8K、SVAMP、ASDiv、GSM-Hard
  - 进阶：MATH-500、AIME24、AIME25、Minerva
  - 统一答案抽取与验证协议（归一化精确、数值、符号、集合/元组等价）。
- **Backbone**：默认 Qwen3-8B；另用 Qwen3-4B 做跨规模验证。
- **对比方法（三类）**：
  1. **已发布 checkpoint**：AgenticQwen、EnvScaler、AgentSkiller、Klear-AgentForge（直接评测作者公开权重）。
  2. **已发布合成语料**：MetaMathQA、ScaleQuest-Math、OpenMathInstruct-2 —— 各采样 **2,940** 道题（与 SynCo 验证通过任务数严格对齐），同一 Qwen3 learner、同一 GRPO 实现/rollout 配置/优化预算。
  3. **受控基线**：Static-Pool GRPO、Offline-Augment GRPO、Reject-Sample SFT、R-Zero（交替式自进化），以及 **SynCo (Frozen Synth.)**（保留在线能力条件合成，但冻结 Synthesizer 参数）——这是隔离"联合优化合成策略"增益的核心消融。
- **训练配置**：UnityMAS-O 多智能体 RL 框架 + GRPO，vLLM 作 rollout 后端；每迭代 32 个合成任务，`K = 4`；actor lr `1e-6`，10 步 warmup，weight decay 0.1，**无 KL 惩罚**；Synthesizer/Reasoner 温度 1.0/0.9，top-p 0.95；评测温度 0.6、top-p 0.95；共 **100 训练步**，生成 3,200 候选、2,940 通过（91.9% 接受率），**无人工标注、无外部 LLM API 调用**。
- **研究问题（RQ1–RQ8）**：整体性能、课程演化、增益归因、合成信号与梯度任务的对齐、事前难度能否预测梯度效用、训练效率、与学习者能力边界的匹配度、优化动力学。
