## 摘要
大语言模型（LLM）智能体正从对话助手演化为具备自主规划、工具使用和复杂任务执行能力的协作智能体（Cowork Agents）。金融分析要求这些智能体整合跨文档证据并执行多步数值推理，但由专家编写任务成本高昂，而直接利用 LLM 合成则难以生成具有可靠答案的高难度任务。我们提出 Navalia，一个面向协作智能体的框架，将可验证任务合成与长时程后训练相结合。Navalia 以企业财务报告为数据源，从完整事实集中语义选择支持证据，并构建可执行计算链，以生成具有可追溯证据和步骤间真实数据依赖的分析任务。我们进一步使用独立的 LLM 审查和程序化检查来验证证据一致性与答案正确性。随后，将验证后的任务用于轨迹收集、冷启动监督微调（SFT）和强化学习（RL），以提升长时程任务执行能力。Navalia 基于 Qwen3.6-35B-A3B 初始化，在全部五个基准上均较基座模型取得一致提升：OfficeQA Pro、FinSearchComp、Finance Agent Benchmark、APEX-Agents-AA 和 Workspace-Bench-Lite。这些结果表明，Navalia 提升了证据整合、工具使用和长时程任务执行能力，并可泛化到更广泛的协作场景，包括通用办公任务。

## Abstract
Large language model (LLM) agents are evolving from conversational assistants into Cowork Agents capable of autonomous planning, tool use, and complex task execution. Financial analysis requires these agents to integrate cross-document evidence and perform multistep numerical reasoning, but expert task authoring is costly, while direct LLM synthesis struggles to produce challenging tasks with reliable answers. We introduce Navalia, a framework for Cowork Agents that combines verifiable task synthesis with long-horizon post-training. Using corporate financial reports as its data source, Navalia semantically selects supporting evidence from complete fact sets and constructs executable computation chains to generate analytical tasks with traceable evidence and actual data dependencies between steps. We further use independent LLM review and programmatic checks to verify evidence consistency and answer correctness. The verified tasks are then used for trajectory collection, cold-start supervised fine-tuning (SFT), and reinforcement learning (RL) to improve long-horizon task execution. Navalia, initialized from Qwen3.6-35B-A3B, achieves consistent gains over the base model across all five benchmarks: OfficeQA Pro, FinSearchComp, Finance Agent Benchmark, APEX-Agents-AA, and Workspace-Bench-Lite. These results demonstrate that Navalia improves evidence integration, tool use, and long-horizon task execution capabilities and generalizes to broader Cowork settings, including general office tasks.

## 2. 方法论

### 2.1 核心思想

- 以企业公开财报为数据源，构建**文档视图 + 事实视图**的双视角表示：文档视图提供智能体可交互检索的环境，事实视图（结构化数值+元信息）支撑任务构造与校验。
- 任务形式化表示为 \(T=(q, y, C, F^+, G, a, \theta)\)：问题、参考答案、交互环境、可追溯支持事实集、可执行计算链、任务锚点（公司/报告期/指标定义与口径）、算子参数。
- 生成流程：**算子采样 → 文档覆盖检查 → 语义选证 → 可执行计算链 → 数值求值 → 问题生成 → 独立审查 + 程序化校验**。

### 2.2 关键技术与流程细节

- **双视角表示**：每份报告 \(d \mapsto (r(d), F(d))\)。\(r(d)\) 解析为保留正文、标题与表格结构的 Markdown；\(F(d)\) 为结构化事实，记录数值、单位、源位置、表上下文、报告期、指标定义、报告范围、版本，信息不完整的记录被剔除；汇总为全局事实库 \(F=\bigcup_d F(d)\)。
- **算子驱动任务设计**：预定义算子/复合模板集合 \(O\)（跨期聚合、趋势对比、统计分析、回归、数值变换、跨公司分析等），按 \(o\sim p(o)\)、\(a\sim p(a\mid o,F)\)、\(\theta\sim p(\theta\mid o)\) 采样，并检查时序连续性、跨公司可比性、多步数据覆盖；不满足则重采样。随后确定候选文档集 \(D_{cand}\)，并从同公司其他报告期与同业公司采样**干扰文档**共同构成环境 \(C\)。
- **语义选证（非规则预过滤）**：LLM 结合算子、锚点、参数及事实的报告期/口径/单位/上下文逐条判断；候选集过大时先做**文档内预筛选**再跨文档联合选择，得到 \(F^+=\mathrm{Select}(o,a,\theta;\tilde F_{cand})\)；若覆盖不足或口径不符则丢弃重采样。此设计旨在避免关键词/固定指标规则导致的证据遗漏。
- **可执行计算链**：简单单步任务由 LLM 直接推导；回归、预测、统计等复杂计算由预定义数值程序**确定性执行**以降低中间误差。多步任务由复合模板串接，链式表达为 \(z_1=o_1(x_1;\theta_1)\)、\(z_k=o_k(z_{k-1},x_k;\theta_k)\)，后续步骤必须使用前序输出，从而排除"名义多步、无真实依赖"的伪任务；数据缺失、类型不兼容或求值失败即丢弃。链输出经单位换算、精度调整与格式归一化得到参考答案 \(y\)。
- **问题生成与质量控制**：在算子、锚点、参数与计算链约束下生成问题 \(q\)，所有影响答案的约束（公司、报告期、指标、口径、算法参数、单位/精度/输出格式）必须显式保留。之后由**独立审查模型**在不复用生成推理的前提下自行推导答案并与 \(y\) 比对；再经**程序化检查**（非最终步骤输出是否被后续步骤使用、问题报告期与事实记录是否一致）。双重通过才保留。
- **冷启动 SFT**：用强教师模型在同一环境中产出完整交互轨迹；先按最终答案正确性、工具调用合法性、最少交互轮数做轨迹级过滤，再按算子/模板分能力池均匀采样；对保留轨迹做轮级质量评估，低质量响应仅作上下文、不参与监督。采用 FIFO 上下文管理，样本步长 10 轮，每样本含任务指令 + 至多 20 轮历史 + 至多 10 轮新交互；交叉熵损失仅作用于通过质量评估的新生成响应，监督区间互不重叠。
- **长时程 RL**：以 SFT 模型为初始策略，复用同一 ReAct harness 与 FIFO 机制在线采样，采用组相对策略梯度。任务筛选保留"有成功也有失败"的任务，全失败任务仅在更强模型可解时保留。每条问题采样 \(G\) 条轨迹 \(\tau_g=(s_{g,1},\dots,s_{g,J_g})\)，以最终段（Anchor）计算任务奖励 \(R_g\)，组相对优势**跨所有分段共享**，使早期检索与分析行为也能获得最终结果反馈；动态采样仅保留组内奖励方差非零的任务组；被生成长度截断的轨迹其奖励仍参与优势与采样统计，但全部 token 被掩码，避免截断失败惩罚此前的有效探索。策略损失按批次内有效 token

- **策略损失与优化细节（续）**：设第 \(b\) 个批次的有效 token 集合为 \(\mathcal{V}_b\)，则损失为
  \[
  \mathcal{L}(\phi)=-\frac{1}{\sum_{b\in\mathcal{B}}|\mathcal{V}_b|}\sum_{b\in\mathcal{B}}\sum_{t\in\mathcal{V}_b}\rho_{b,t}\,\hat{A}_{b,t}+\beta\,\mathrm{KL}\big(\pi_\phi\,\|\,\pi_{\mathrm{ref}}\big)
  \]
  其中 \(\rho_{b,t}\) 为重要性采样比并经裁剪，\(\hat{A}_{b,t}\) 为组内归一化后、跨分段共享的优势估计，\(\beta\) 为 KL 系数，\(\pi_{\mathrm{ref}}\) 为 SFT 初始策略。该归一化方式保证不同长度轨迹、不同分段数在梯度中的权重均衡，避免长轨迹与截断轨迹主导更新。
- **训练与环境一致性**：SFT 与 RL 复用同一 ReAct harness、同一工具集与同一 FIFO 上下文策略，仅在采样方式（教师轨迹 vs. 在线自采样）与损失（纯交叉熵 vs. 策略梯度 + KL）上不同，从而降低"训练-推理分布错配"。

## 3. 实验设计

- **数据与环境**：以企业公开财报构建文档视图与事实库，任务覆盖跨报告期聚合、趋势对比、统计与回归、跨公司比较等多类算子与复合模板；环境内含同公司其他报告期与同业公司构成的干扰文档，使检索与证据甄别成为任务的内在组成部分。
- **训练阶段**：先以强教师模型在环境中采样轨迹做冷启动 SFT（轨迹级 + 轮级双重过滤、按能力池均衡采样），再以 SFT 模型为初始策略进行长时程 RL（组相对策略梯度、任务筛选、动态采样）。
- **评测维度**（依据论文的验证目标可归纳为）：
  1. **最终答案正确性**：数值答案与参考答案在单位、精度、格式归一化后的一致性；
  2. **过程质量**：工具调用合法性与效率（交互轮数）、证据可溯源性（是否引用支持事实对应的文档位置）、多步依赖是否真实成立；
  3. **泛化与迁移**：在未见公司/报告期上的表现，以及在非金融办公协作类任务上的迁移表现；
  4. **对照基线**：基座模型、仅 SFT、仅提示/少样本、以及不带真实数据依赖的合成任务训练版本等。

## 4. 主要结果与发现

- **任务合成的有效性**：通过"算子采样—语义选证—可执行计算链—独立审查 + 程序化校验"的多重约束，任务在证据可溯源、答案可验证、步骤间存在真实数据依赖三方面同时得到保证；相较自由生成的问答，伪多步（名义多步但步骤间无依赖）与口径混用类错误显著减少。
- **冷启动 SFT 的作用**：轨迹级过滤（最终答案正确、工具调用合法、交互轮数较少）+ 轮级质量评估（低质量响应仅作上下文、不参与监督）使模型学到"先定位证据、再计算、再校验"的稳定行为模式，而非表面的格式模仿。
- **长时程 RL 的增益**：跨分段共享的组相对优势使早期检索与选证行为能够获得最终结果的反馈，缓解长时程任务中"信用分配稀疏"的问题；任务筛选（保留有成功也有失败的样本）与动态采样（仅保留组内奖励方差非零的任务组）提升了训练信号的密度与稳定性；对截断轨迹"奖励参与统计、token 全部掩码"的处理避免了因生成长度限制而惩罚此前的有效探索。
- **整体趋势**：SFT → RL 的两阶段流水线在最终答案正确性与过程质量上相较基座与仅 SFT 版本均有一致提升；在未见公司与报告期上的表现表明模型学到的是可迁移的检索—计算—校验流程，而非对特定文档的记忆；在非金融协作任务上的迁移表现说明该流程具有一定的领域通用性。

## 5. 分析、消融与讨论要点

- **语义选证 vs. 规则预过滤**：消融显示，基于关键词或固定指标规则的预过滤会遗漏口径变体与表述差异导致的证据，进而降低任务可解率与训练信号质量；LLM 语义判断 + 候选集过大时的"文档内预筛选 → 跨文档联合选择"是兼顾覆盖率与成本的关键。
- **可执行计算链 vs. 纯 LLM 推导**：对回归、预测、统计等复杂算子采用确定性数值程序执行，可显著降低中间步骤的数值漂移；而简单单步任务交由 LLM 推导，保持任务的自然性与多样性。
- **独立审查 + 程序化校验的双重把关**：独立审查模型不复用生成推理，避免"自证其说"；程序化检查（非最终步骤输出是否被后续使用、问题报告期与事实记录是否一致）则从结构上排除伪多步与口径错配，两者互补。
- **上下文管理的影响**：FIFO 上下文与"至多 20 轮历史 + 至多 10 轮新交互"的样本切分，使长轨迹可在有限上下文内被有效监督，同时保证监督区间互不重叠、不重复计权。
- **潜在偏差与风险**（可作为客观评述）：任务分布受算子集合与财报数据覆盖范围约束，可能对算子未覆盖的推理类型泛化有限；参考答案依赖结构化事实抽取质量，抽取误差会传导至任务与评测；长时程 RL 对教师模型能力与任务难度分布较敏感。

## 6. 贡献、局限与启示

- **主要贡献**：
  1. 提出**双视角（文档视图 + 事实视图）**的财报环境表示，使"可交互检索"与"可验证构造"在同一数据源上统一；
  2. 提出**算子驱动 + 语义选证 + 可执行计算链 + 双重校验**的可验证任务合成流程，从机制上排除伪多步与口径混用；
  3. 给出**冷启动 SFT + 长时程 RL** 的完整后训练流水线，包括轨迹/轮级过滤、跨分段共享优势、任务筛选与截断处理等工程细节，提升可复现性；
  4. 在金融分析任务上验证能力可迁移至更广泛的办公协作场景。
- **局限**：算子与模板集合的覆盖范围决定了任务多样性上限；结构化事实的质量是任务正确性的前置条件；评测以答案一致性与过程指标为主，对"分析论证质量"等更主观的维度覆盖有限；长时程 RL 的训练成本较高。
- **启示**：对需要多步工具交互的领域智能体，"先构造可验证、有真实依赖的任务，再设计能对长时程行为做信用分配的训练方法"是一条可复用的路径；其中**证据可溯源**与**步骤真实依赖**应作为任务质量的一等约束，而非事后过滤项。
