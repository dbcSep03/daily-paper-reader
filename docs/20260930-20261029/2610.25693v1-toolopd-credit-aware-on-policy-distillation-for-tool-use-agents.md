## 摘要
同策略蒸馏（OPD）通过在学生模型生成的轨迹上由教师模型提供密集的 token 级监督，增强小型语言智能体的能力。然而，标准 OPD 隐含地假设信用在长时程轨迹上均匀分布，并对不同动作赋予相同强度的教师监督。通过信用分布分析和结果反转反事实实验，我们发现轨迹信用集中在少量关键动作上。此外，即使保持轨迹固定，仅反转最终结果也会显著改变分配给多个交互轮次的信用。这些发现表明，均匀信用假设无法识别关键决策，并最终降低模型的推理准确率。为应对这些挑战，我们提出 ToolOPD，一种面向长时程工具使用的结果感知同策略蒸馏框架。ToolOPD 首先将每条已完成轨迹及其结果总结为可复用的事后技能。然后，它度量该技能如何改变教师对每个学生动作 token 的概率，并将该变化转化为结果感知信用。由此得到的信用保留了支持成功决策或抑制失败决策的监督，同时压制无关和冲突信号。ToolOPD 使用这些信用对动作级蒸馏损失进行重加权，并与强化学习联合优化。在多个长时程工具交互基准上的大量实验表明，ToolOPD 显著优于现有的强化学习和自蒸馏基线。

## Abstract
On-policy distillation (OPD) enhances the capabilities of small language agents by providing dense, token-level supervision from a teacher model on student-generated trajectories. However, standard OPD implicitly assumes that credit is uniformly distributed across long-horizon trajectories, assigning the same strength of teacher supervision to different actions. Through credit-distribution analysis and outcome-reversal counterfactual experiments, we find that trajectory credit is concentrated on a small number of critical actions. Moreover, even when the trajectory is held fixed, reversing only the final outcome substantially changes the credit assigned to multiple interaction turns. These findings show that the uniform-credit assumption fails to identify critical decisions and ultimately degrades the model's reasoning accuracy. To address these challenges, we propose ToolOPD, an outcome-aware on-policy distillation framework designed for long-horizon tool use. ToolOPD first summarizes each completed trajectory and its outcome into a reusable hindsight skill. It then measures how this skill changes the teacher's probability of each student action token and converts the change into outcome-aware credit. The resulting credit preserves supervision that supports successful decisions or discourages failed ones, while suppressing irrelevant and conflicting signals. ToolOPD uses these credits to reweight the action-level distillation loss and jointly optimizes it with reinforcement learning. Extensive experiments across multiple long-horizon tool interaction benchmarks demonstrate that ToolOPD significantly outperforms existing reinforcement learning and self-distillation baselines.

## 1. 核心问题与研究动机

- **背景**：长时程工具使用任务（如 ALFWorld、WebShop、多跳工具调用）通常需要数十到数百轮交互，但环境只在轨迹结束时给出一个稀疏的成功/失败奖励，中间动作对最终结果的贡献难以归因。
- **现有方法**：同策略蒸馏（OPD）让学生在自己生成的轨迹上接受教师模型的密集 token 级监督，以缓解稀疏奖励问题。
- **核心缺陷**：标准 OPD 隐含假设"信用在整条轨迹上均匀分布"，对所有动作施加同等强度的教师监督，无法区分关键工具决策与例行过渡动作。
- **实证发现（论文的三个诊断实验）**：
  - **信用高度集中**：ALFWorld 上信用最高的前 20% 交互轮贡献了 74.2% 的总信用，其余 80% 仅占 25.8%。
  - **信用结果敏感**：固定任务与状态–动作序列、仅反转最终结果标签，会改变 ALFWorld/WebShop/SearchQA 中 55.2%/25.0%/50.0% 交互轮的信用分配。
  - **监督信号冲突**：均匀蒸馏下，与最终结果方向冲突的教师证据占全部教师证据的 53.5%。
- **整体含义**：有效的长时程蒸馏必须同时回答两个问题——哪些动作是关键决策，以及教师信号是否与轨迹结果一致；否则均匀监督会稀释关键信号甚至引入错误引导，降低推理准确率。

## 2. 方法论：ToolOPD 框架

- **核心思想**：将稀疏的轨迹级信用转化为稠密的、结果感知的动作级信用，用该信用重加权动作级蒸馏损失，并与 GRPO 强化学习联合优化；教师参数全程冻结，梯度只更新学生。
- **关键技术流程（四步）**：

  1. **结果条件化的事后技能归纳（Hindsight Skill Induction）**
     - 教师基于完整轨迹与最终结果生成一条简洁可复用技能：`z_i = G_φ(τ_i, y_i)`。
     - 成功轨迹总结有效流程/关键决策；失败轨迹总结错误根因与规避原则；格式约束为 "Rule Name: imperative guidance"，防止教师直接重写轨迹。
     - 同一轨迹内所有状态共享该技能；推理阶段学生可独立部署，不产生额外推理开销。

  2. **结果非对称的技能相关性（Outcome-Asymmetric Skill Relevance）**
     - 对每个学生实际采样的动作 token，比较教师"有技能"与"无技能"条件下的对数概率差：
       `Δ_{i,t,k} = log q^z_φ(a|s) − log q^0_φ(a|s)`。
     - 引入方向因子 `d_i = 2y_i − 1`，token 级相关度：
       `c_{i,t,k} = m_{i,t,k} · [2σ(β_h · d_i · Δ_{i,t,k}) − 1]_+`。
     - **非对称性**：成功轨迹只保留技能提升动作概率的正向信号；失败轨迹只保留技能降低动作概率的正向信号；与结果方向不一致的影响被截断为 0。
     - 在当前动作内对 token 相关度取平均，得到决策级权重 `H_{i,t}`，作为蒸馏权重。

  3. **动作级同策略蒸馏（Action-Level OPD）**
     - 损失为 `L_ToolOPD = E[Σ_t H_{i,t} · D_KL(q^z_φ(·|s_{i,t}) ‖ π_θ(·|s_{i,t}))]`。
     - 用重要性采样估计 KL，定义对数比 `ℓ = log q^z_φ − log π_θ`，裁剪后 `r = exp(clip(ℓ, −c, c))`（c=5）。
     - 单 token KL 的无偏估计形式为 `r log r − r + 1`，最终损失仅对 `<action>` token 求和并归一化。
     - 只监督可执行决策 token，不干扰 `<think>` 等自然语言推理，保留学生自身推理表达范式。

  4. **与 GRPO 联合优化**
     - GRPO 使用组内相对优势 `A_i = (R_i − mean(R)) / (std(R) + ε)`，带 PPO 式裁剪。
     - 总目标：`L_total = L_GRPO + λ_OPD · L_ToolOPD`。
     - `λ_OPD` 取较小值，使教师信号作为辅助正则，引导优化方向但不压制 RL 主梯度。

- **算法要点**：每步采样 G 条学生轨迹 → 计算 GRPO 优势 → 教师生成事后技能 → 计算非对称信用 `H_{i,t}` → 加权动作级 KL → 联合更新学生参数。

## 6. 主要结论与发现

- **诊断层面**：长时程 OPD 的信用高度

- **诊断层面**：长时程 OPD 的信用高度集中且对最终结果敏感，均匀 token 级监督会使大量教师证据与轨迹成败方向冲突；因此“平均用力”的蒸馏不仅稀释关键决策信号，还可能把失败轨迹中的错误行为一并模仿。
- **方法层面**：ToolOPD 通过“事后技能归纳 + 结果非对称相关性 + 动作级加权 KL + GRPO 联合优化”，把轨迹级稀疏奖励转化为动作级稠密信用，且只监督 `<action>` 决策 token，保留学生自身 `<think>` 推理风格。
- **性能层面**：
  - 在 ALFWorld、SearchQA、WebShop 三类交互任务上，ToolOPD 在多数平均指标上优于 GRPO、标准 OPD、TCOD、OPSD、ATOD、TurnSight 及技能条件自蒸馏基线，说明结果感知信用分配对具身交互与多跳搜索均有效。
  - 在 FTRL 工具调用训练设置下，ToolOPD 的主要优势体现在并行工具调用指标 Solve-P 与分布外 ToolHop 多跳工具依赖准确率；Solve-R/F1 并非全面领先，表明其收益更偏向“选对工具与调用结构”，而非所有函数调用细项同步提升。
  - 在 BFCL 与 ToolHop 的分布外评测中，仅用 FTRL 训练即可获得一定泛化增益，说明动作级信用重加权有助于学生学到可迁移的工具使用原则，而不是记忆特定任务轨迹。
  - 训练动态显示，ToolOPD 能缓解师生差距扩大与策略熵异常变化，教师信号主要起方向性正则作用，未完全压制 RL 主梯度。
- **消融层面**：从 GRPO → 朴素 OPD → Skill-OPD → 完整 ToolOPD 的渐进消融表明，性能提升并非仅来自“引入教师”或“引入技能文本”，结果非对称相关性与动作级重加权是增益关键；`λ_OPD` 在较小范围内较稳定，过大时教师蒸馏会与 RL 目标竞争。
- **成本—收益层面**：ToolOPD 的每 token 训练成本显著高于 GRPO/MatchTIR，但低于 TurnSight；达到相同 FTRL F1 所需 GPU-hours 少于 GRPO 与 TurnSight、多于 MatchTIR。其定位是以额外前向与技能归纳计算换取更精准信用分配，而非追求吞吐最优。

## 7. 局限性与审慎解读

- **信用估计依赖教师与结果标签**：事后技能由固定教师生成，非对称相关性又以最终成败作为方向因子；若教师先验有偏、结果标签噪声较大，或失败轨迹包含“偶然正确”的中间决策，信用权重可能被错误截断。
- **反事实诊断样本量偏小**：结果反转实验仅涉及少量轨迹与交互轮，虽能直观说明信用对结果敏感，但统计稳健性和跨任务可推广性仍需更大规模验证。
- **基线复现公平性存疑**：部分基线在特定表格中异常偏低，可能受训练预算、prompt、工具环境或超参适配影响；因此应更关注同配置下的相对趋势，而非绝对排名。
- **任务间差异被平均值掩盖**：ALFWorld 子任务、WebShop Score/成功率、FTRL 的 P/R/F1 之间存在不一致，ToolOPD 并非所有子项最优；实际部署需按任务目标选择权重与蒸馏强度。
- **教师质量与规模未充分扫描**：主实验固定为 GRPO 训练的 Qwen3-4B 教师，尚未系统回答教师强弱、教师与学生能力差距、教师错误率对 ToolOPD 的影响。
- **推理阶段虽无额外开销，但训练阶段依赖教师多次前向**：技能生成与“有/无技能”双条件概率比较带来显著训练成本；在超长轨迹或大工具库场景下，成本可能进一步放大。
- **理论保证有限**：论文主要提供诊断证据与实证增益，尚未给出“结果非对称信用”在何种假设下能一致估计动作因果贡献的形式化保证。

- **工程实践启示**：
  - 对长时程智能体，应优先监督可执行动作 token，避免对自然语言思考过程施加过强模仿约束。

- **可拓展方向**：多教师集成与教师置信度加权、基于蒙特卡洛或反事实重采样的信用估计、将结果非对称思想推广到过程奖励模型与多智能体协作、以及在更大模型和真实工具环境中的验证。

## 9. 总体评价

ToolOPD 是一篇问题意识清晰、诊断实验有说服力的智能体蒸馏工作。其核心贡献不在于提出全新的 RL 算法，而在于揭示标准 OPD 在长时程工具使用中的“信用均匀化”缺陷，并给出一个结果感知、动作级、可与 GRPO 联合训练的实用修正方案。实验覆盖较广、消融较完整、成本分析较透明，具备较强的可复现性和工程参考价值。与此同时，论文的绝对性能优势存在任务异质性，部分基线复现与反事实诊断的统计规模有限，教师质量鲁棒性和理论保证仍有提升空间。总体而言，适合作为“长时程智能体蒸馏与信用分配”方向的重要实证型参考工作，而非普适最优解。
