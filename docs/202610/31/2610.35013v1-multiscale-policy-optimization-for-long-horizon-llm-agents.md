## 摘要
长时程LLM智能体通过完整的助手轮次与环境交互，同时在每个轮次中逐词元生成动作。我们观察到，critic价值主要在轮次之间发生变化，这促使我们将优化锚定在轮次层面，并在词元之间进行更精细的信用分配。我们提出多尺度策略优化（MPO），将多尺度优势估计（MAE）与轮次级重要性采样相结合，以在轮次尺度上对齐信用分配与策略更新。在搜索、工具使用和自动化任务上，使用4B与30B-A3B模型开展的大量实验表明，该方法相较强RL基线取得了持续增益。

## Abstract
Long-horizon LLM agents interact with their environments through complete assistant turns while generating each action token by token. We observe that critic values vary primarily across turns, motivating optimization anchored at turns with finer credit allocation among tokens. We propose Multiscale Policy Optimization (MPO), combining Multiscale Advantage Estimation (MAE) and turn-level importance sampling to align credit assignment and policy updates at the turn scale. Extensive experiments across search, tool-use, and automation tasks with 4B and 30B-A3B models demonstrate consistent gains over strong RL baselines.

## 1. 核心问题与研究动机

- **背景**：长时程 LLM 智能体（搜索、工具调用、自动化操作）以“完整助手轮次（assistant turn）”为单位与环境交互，但策略本身是逐 token 自回归生成；任务通常只在轨迹终止时给出一个稀疏的终局奖励。
- **核心矛盾（两个尺度不匹配）**：
  - **信用分配尺度**：终局奖励需要被归因到“哪一次交互（轮次）起了作用”，同时还要区分同一轮内部“哪些 token 起了作用”。
  - **策略更新尺度**：重要性修正应针对“整轮输出概率”的变化，但又不能抹平轮内的 token 差异。
- **现有方法的两类缺口**：
  - **无 critic、组相对类**（GRPO、DAPO、GSPO）：一条序列共享一个优势，无法区分轮次与 token 的贡献。
  - **有 critic、token 级类**（PPO、VC-PPO、VAPO、SAO）：把每个 token 当作动作，信用更细，但没有显式区分“轮内生成”与“轮级环境交互”。
- **关键实证观察（动机来源）**：作者统计了某次搜索智能体训练中 8 个 checkpoint、2048 条轨迹、16323 个轮次的 critic 值，发现：

## 2. 方法论：多尺度策略优化（MPO）

### 2.1 问题形式化
- 轨迹 τ = (o₀, a₀, o₁, a₁, …, o_T, a_T)，轮次 t = 0…T；策略按轮分解：π_θ(a_t|h_t) = ∏_i π_θ(a_{t,i}|h_{t,i})。
- 奖励仅在终止处给出：r_{t,i} = R(τ) 当且仅当 t=T, i=L_T，其余为 0；目标 J(θ)=E[R(τ)]。
- 把完整轮次 a_t 视为**宏动作（macro action）**，h_t 为状态；Lemma 1 证明宏/ token 两种描述在无损细化、γ=1 下目标与梯度一致（∇log π(a_t|h_t) = Σ_i ∇log π(a_{t,i}|h_{t,i})）。

### 2.2 理论分析（为什么要在轮尺度上做）
- **Lemma 2（宏性能差）**：J(π′)−J(π) = Σ_t E_{h_t∼d^{π′}_t, a_t∼π′}[A^π_t]，其替代目标 S_M = E_π Σ_t (ρ_t − 1) A^π_t，其中 ρ_t = π′(a_t|h_t)/π(a_t|h_t) 为**整轮重要性比**。
- **Theorem 1（轮级单调改进界）**：J(π′)−J(π) ≥ S_M − 2A_max·T(T+1)·α_M²，α_M 为整轮输出分布的总变差上界。
- **Theorem 2（token 替代目标的额外代价）**：token 级替代目标 S_T 与 S_M 之差被 2(T+1)·A^tok_max·L_max(L_max−1)·α_T² 约束，来源是“轮内前缀分布偏移”。
- **KL 换算**：统一 token KL 上限 δ 下，token 界的额外惩罚项约为 (T+1)(L_max−1)Δ，即在同等 KL 预算下 token 替代目标更“贵”。
- 附录还给出：估计器鲁棒性（Theorem 3）、边界 critic 误差下的轮级保证（Corollary 1）、token-GAE 的偏置与更差惩罚（Proposition 1、Corollary 2），以及一个**内点 critic 误差可逆转更新方向**的反例（Proposition 2）。

### 2.3 多尺度优势估计（MAE）
- 记号：V_{t,i}=V(h_{t,i})，边界处 V_{t,L_t+1}:=V_{t+1,1}，V_{T+1,1}:=0；TD 残差 δ_{t,i}=r_{t,i}+V_{t,i+1}−V_{t,i}。
- **轮级信用传播**：轮内 TD 残差求和可消去所有内部值预测，得 δ^turn_t = 1{t=T}R(τ)+V_{t+1,1}−V_{t,1}；再在轮轴上做 GAE：A^turn_t = Σ_{ℓ=0}^{T−t} λ^ℓ δ^turn_{t+ℓ}。该信用“每轮衰减一次”，与轮长和内部预测无关。
- **轮内信用分配**：局部 trace A^intra_{t,i} = Σ_{j=i}^{L_t} λ_intra^{j−i} δ_{t,j}（仅在轮内截断，末位残差仍回传到 V_{t+1,1}）。
- **带约束的投影组合**（核心公式）：要求 token 权重的均值等于轮级估计，同时尽量贴近缩放后的局部信号，即
  min_w ½‖w − βA^intra_t‖²  s.t. (1/L_t)Σ_i w_i = A^turn_t，
  解得 **A^MAE_{t,i} = A^turn_t + β(A^intra_{t,i} − Ā^intra_t)**，其中 Ā^intra_t 为轮内均值。
  - β=0 退化为“整轮广播”（所有 token 共享同一优势）；
  - 中心化保证不改变轮级共享信用，只调整轮内相对差异。

### 2.4 轮级重要性修正（关键工程技巧）
- 定义 token 比 ρ_{t,i}=π_θ(a_{t,i}|h_{t,i})/π(a_{t,i}|h_{t,i})，整轮比 ρ_t=∏_i ρ_{t,i}。
- 若直接用 ρ_t 乘所有 MAE 优势，中心化的局部修正会在未截断求和中相互抵消；因此采用 **stop-gradient 构造**：
  ρ̃_{t,i}(θ) = ρ_{t,i}(θ)·sg(∏_{j≠i} ρ_{t,j}(θ))。
  - 前向：ρ̃_{t,i}=ρ_t，即每个 token 都获得“整轮权重”并参与同一裁剪；
  - 反向：∇ρ̃_{t,i}=ρ_t·∇log π_θ(a_{t,i}|h_{t,i})，即每个 token 的梯度仍由**自己的 MAE 优势**加权。
