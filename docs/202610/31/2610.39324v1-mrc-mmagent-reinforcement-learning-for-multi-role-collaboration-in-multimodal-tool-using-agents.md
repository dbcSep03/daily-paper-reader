## 摘要
多模态工具使用智能体通过让视觉语言模型获取外部信息与能力，使其能够解决仅依靠视觉上下文无法处理的知识密集型和视觉复杂任务。然而，现有强化学习流程大多训练单一角色的智能体，利用终端奖励进行搜索与回答，忽视了人类在搜索过程中如何检查检索证据、重构查询并修正结论。因此，这些方法无法在完整交互轨迹上优化这种自我修正过程。我们提出 MRC-MMAgent，一种多角色协作强化学习框架，将轨迹评估与继续求解直接融入可执行智能体循环。首先，该框架建立了一个整合求解、检查和继续的多角色协作循环，使智能体能够通过工具获取证据、评估先前轨迹，并在当前答案支撑不足时恢复问题求解。其次，我们引入一种角色耦合学习目标，将任务成功、交互有效性和成功修正与所有角色所生成决策的全轨迹策略优化相结合。大量实验表明，仅使用原始基线训练集而不构建额外数据集，我们的方法始终优于相应的基础模型，并在多个基准上取得领先或极具竞争力的性能。

## Abstract
Multimodal tool-using agents augment vision-language models with access to external information and capabilities, enabling them to solve knowledge-intensive and visually complex tasks that cannot be addressed using visual context alone. However, existing reinforcement learning pipelines largely train single-role agents to search and answer using terminal rewards, overlooking how humans inspect retrieved evidence, reformulate queries, and revise conclusions during search. Consequently, they fail to optimize this self-corrective process over complete interaction trajectories. We propose MRC-MMAgent, a multi-role collaborative reinforcement learning framework that incorporates trajectory assessment and continuation directly into the executable agent loop. First, the framework establishes a multi-role collaborative loop that integrates solving, inspection, and continuation, enabling the agent to acquire evidence through tools, evaluate the preceding trajectory, and resume problem solving when the current answer is insufficiently supported. Second, we introduce a role-coupled learning objective that combines task success, interaction validity, and successful correction with full-trajectory policy optimization across the decisions generated by all roles. Extensive experiments show that, using only the original baseline training set without constructing additional datasets, our method consistently outperforms the corresponding base models and achieves leading or highly competitive performance across benchmarks.

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）在感知、识别和视觉问答上进步显著，但很多问题仅靠图像无法回答，需要借助反向图搜、文本搜索、图像缩放、检索等外部工具。多模态工具智能体因此成为解决知识密集型和视觉复杂任务的重要范式。
- **现有强化学习流程的局限**：
  - 大多把智能体训练成**单一角色的求解器**，只用最终答案的终端奖励进行优化。
  - 缺少对人类搜索过程的建模：人类会检查已检索证据是否充分、改写查询、在答案支撑不足时继续搜索并修正结论。
  - 单角色循环即使检索到相关片段，也可能基于错误的比较依据作答；简单加入“反思”往往只是重复或合理化初始推理，不能形成可训练的证据评估与轨迹控制机制。
- **论文的核心主张**：应将“求解—检查—继续求解”组织为统一可执行循环，并把证据充分性判断变成可训练的控制决策；同时用**全轨迹、角色耦合**的强化学习目标联合优化所有角色，而不是只优化终端答案。

## 2. 方法论

### 2.1 多角色协作智能体循环

- 使用一个共享策略 \(\pi_\theta\)，通过不同冻结提示词扮演三个角色：
  - **Solver 1（初始求解器）**：进行推理、调用工具、收集视觉—文本证据，并提出候选答案。
  - **Inspector（检查器）**：在不访问参考答案、正确性标签和未来结果的情况下，审查当前轨迹与候选答案，判断证据是否充分。
  - **Solver 2（继续求解器）**：当 Inspector 判定需要继续时，基于已有证据、被拒绝的候选答案和检查反馈，继续工具调用并修正答案。
- Inspector 输出两类决策：
  - **finalize**：证据充分，接受候选答案并结束。
  - **continue**：证据不足、冲突或支撑不充分，生成反馈并交回 Solver 2。
- 循环最多执行 \(N_m\) 次继续；默认 \(N_m=1\)。完整轨迹包括初始求解、检查、继续求解及其工具观察。
- 关键设计：Inspector 的输入中**不包含参考答案 \(y^\star\)、候选答案正确性 \(Acc(P_k)\) 和最终答案 \(y_f\)**，因此检查是“无参考答案”的证据充分性判断，而不是拿答案对答案。

### 2.2 角色耦合轨迹奖励

每个完整轨迹获得三类奖励：

- **答案正确性 \(R_{acc}\)**：最终答案是否正确，取值 0/1。
- **交互有效性 \(R_{fmt}\)**：工具调用是否合法、检查前是否有候选答案、控制决策是否连贯、继续过程是否格式正确，取值 0/1。
- **检查引导的修正奖励 \(R_{corr}\)**：
  - Inspector 触发继续，但初始答案原本正确：0 分（不必要拒绝）。
  - Inspector 触发继续，初始答案错误且继续后修正成功：1 分。
  - Inspector 触发继续，初始答案错误但继续后仍错误：0.5 分（承认检查发现了问题，但修正失败）。
  - Inspector 不触发继续且最终答案正确：1 分。
  - Inspector 不触发继续且最终答案错误：0 分（过早结束）。
- 总奖励为加权和：
  \[
  R(\tau)=\lambda_{acc}R_{acc}+\lambda_{fmt}R_{fmt}+\lambda_{corr}R_{corr}
  \]
  默认权重为 \(0.7,0.1,0.2\)，优先保证正确性，同时约束交互合法性和有效修正。
- 该奖励是初始求解、检查、继续求解三类角色决策的**耦合函数**，而不是三个独立角色奖励的简单拼接。

### 2.3 全轨迹 GRPO 优化

- 对每个问题采样 \(G\) 条完整轨迹，计算组内相对优势：
  \[
  \bar A_{b,g}=\frac{R(\tau_{b,g})-\mathrm{mean}_{g'}R(\tau_{b,g'})}{\mathrm{std}_{g'}R(\tau_{b,g'})+\epsilon}
  \]
- 将同一个轨迹级优势分配给**所有由策略生成的 token**，包括初始求解器、Inspector 和继续求解器的决策 token；工具观察、提示词、桥接消息等非策略生成内容不计算似然损失。
- 论文强调：角色选择性掩码只更新“局部责任角色”的 token，会引入**后验角色归因偏差**；由于角色之间因果耦合，掩码后的梯度一般不等于全轨迹梯度，会改变优化目标。全轨迹 GRPO 则保留完整轨迹似然，与耦合奖励更一致。

## 6. 主要结论与发现

- MRC-MMAgent 在仅使用原始 MMSearch-R1 训练集、不额外构造数据的情况下，稳定优于对应基座模型。
- 7B 版本平均准确率达到 **62.2**，相比 MMSearch-R1-7B 的 51.1 提升约 **11.1 个百分点**；8B 版本平均准确率达到 **68.1**。
- 在搜索密集型任务上，8B 版本相对 SenseNova-MARS-8B 在 FVQA-Test、SimpleVQA、LiveVQA 上分别提升到 74.2、74.3、61.3；但 OpenSearch-VL-8B 在部分指标上仍有优势，说明并非全面绝对领先。
- 在视觉推理任务上，8B 版本取得 V* Bench **93.2**、HR-Bench 4K **82.1**、HR-Bench 8K **78.5**，相对 Qwen3-VL-8B-Instruct 分别提升 +6.8、+3.2、+3.9。
- 消融表明：
  - 联合训练 Solver 与 Inspector 效果最好，整体准确率从 51.1 提升到 64.0。
  - 去掉角色耦合奖励后，FVQA-Test 从 64.0 降到 62.3，说明多角色规范约束和修正奖励重要。
  - 未训练 Inspector 几乎对所有轨迹都输出 continue（98.3%），造成大量不必要修改；训练后 continue 比例降至 60.4%，准确率提升。
  - 两个继续循环相比一个循环没有明显收益，反而增加 token 和工具调用成本，因此默认采用单次继续。
  - 角色耦合奖励权重在 0.1–0.3 范围内表现较稳健。

## 7. 优点

- **问题建模有新意**：把“检查证据是否充分并决定是否继续”显式建模为可训练的控制决策，而不是附带的反思提示。
- **多角色共享策略设计简洁**：同一策略通过不同提示词切换角色，不需要多个独立模型，工程上较优雅。
- **检查器无参考答案**：Inspector 不接触 ground truth，更接近真实应用中的证据审查，避免“偷看答案”。
- **奖励设计较细**：同时考虑答案正确性、交互合法性和修正

有效性，并通过“不必要拒绝—成功修正—失败修正—正确终止—过早终止”的分层打分，把检查行为与最终结果联系起来；相比只用终端答案奖励，信号更密、更能约束角色行为。
- **优化目标与角色结构一致**：论文明确论证了“角色选择性掩码”会带来后验角色归因偏差，并采用全轨迹 GRPO 让同一轨迹优势作用于所有策略生成 token，这与角色间因果耦合的结构相匹配，理论上更自洽。
- **实验对比较全面**：同时覆盖知识密集型搜索问答与高分辨率视觉 grounding 两类任务，既与同规模开源智能体比较，也与闭源通用大模型和零样本智能体比较，并补充了成本—性能分析。
- **消融针对性强**：围绕“是否训练 Inspector”“是否使用角色耦合奖励”“继续循环次数”“奖励权重”等关键设计逐一拆解，能够较直接地定位性能来源。
- **训练数据使用克制**：仅使用原始 MMSearch-R1 训练集，不额外构造 SFT 轨迹或 RL 数据，降低了“数据工程优势”混淆方法贡献的风险，也提升了与既有工作的可比性。

## 8. 局限与不足

- **基线可比性仍有限**：不同 8B 级基线可能基于不同基座模型、不同预训练/后训练数据和不同工具接口，尽管论文强调统一配置，但严格受控比较仍难完全保证；部分 benchmark 上部分基线数值缺失，也会影响整体平均值的公平性。
- **统计稳健性报告不足**：未报告多随机种子运行的均值、方差或显著性检验，单次训练结果可能受初始化、采样和 rollout 方差影响；对于约 1–2 个百分点的提升，统计显著性尚不明确。
- **评估依赖自动评判器**：使用 Qwen3-32B 作为答案评估器，虽然在大规模评测中常见，但可能引入评判偏差，尤其是开放式 VQA 和长答案场景；论文未系统报告人工校验或评判器一致性分析。
- **Inspector 的能力边界未充分刻画**：Inspector 不接触参考答案，这是优点，但也意味着其“证据充分性”判断依赖自身先验和轨迹表征能力；论文未深入分析 Inspector 在何种问题类型上容易误判（如视觉细节缺失、检索噪声、答案歧义），也缺少对误判类型的细粒度统计。
- **继续循环的收益有限**：消融显示 \(N_m=2\) 相比 \(N_m=1\) 没有明显收益且成本更高，说明当前“检查—继续”机制在多次迭代下的增益尚未充分释放；如何让多轮修正持续产生价值仍是开放问题。
- **成本分析仍偏粗**：虽然给出了成本—性能分析，但未系统报告训练总算力、总 GPU 小时、推理延迟和工具调用费用的完整分解；对实际部署而言，工具调用次数和 token 开销的边际收益仍需更细的预算曲线。
- **任务覆盖偏重静态 benchmark**：评测以离线 benchmark 为主，虽提及在线搜索与离线搜索的消融，但对真实动态网络环境、工具失败、检索结果时效性等鲁棒性问题的考察仍有限。
- **角色划分依赖人工提示词**：三个角色通过冻结提示词区分，角色边界和行为规范由人工设计；论文未充分讨论提示词敏感性、角色提示词迁移到其他工具集或其他基座模型时的稳定性。

## 9. 启发与可借鉴点

- **把“是否继续”变成可训练决策**：该工作最有价值的思路，是不把反思当作自然语言提示，而是把“证据是否充分”显式化为 finalize/continue 二值控制动作，并为其设计可验证的轨迹级奖励。这一范式可迁移到代码智能体、文档检索智能体、机器人多步操作等需要“停止或继续”判断的场景。
- **无参考答案的检查器设计**：Inspector 仅基于当前轨迹和候选答案做判断，避免信息泄漏，也更接近真实部署条件；这种“审查者不看答案”的角色隔离，可作为多智能体 RL 中防止角色作弊的通用设计原则。
- **耦合奖励优于角色独立奖励**：论文将初始答案正确性、检查决策和修正结果放入同一奖励函数，使“拒绝正确答”和“接受错误答案”都受到惩罚，避免各角色各自局部最优却整体次优。这对多角色 RL 系统的奖励工程有直接参考价值。
- **全轨迹优化与角色掩码的权衡**：论文关于“角色选择性掩码会改变优化目标”的论证值得重视；在角色间存在因果依赖时，简单按角色切分梯度可能引入归因偏差，全轨迹似然加轨迹级优势是更保守、更一致的选择。
- **单次继续的工程取舍**：实验表明多轮继续收益有限，提示在实际系统中应优先优化“第一次检查的质量”，而不是盲目增加反思轮数；这对控制推理成本和工具调用预算具有现实指导意义。

## 10. 总体评价

该论文围绕多模态工具智能体的强化学习训练，提出了“求解—检查—继续求解”的多角色协作循环，并通过无参考答案的 Inspector、角色耦合轨迹奖励和全轨迹 GRPO，将证据充分性判断转化为可训练的控制决策。方法设计简洁、动机清晰，实验覆盖搜索密集型问答与高分辨率视觉推理两类任务，消融较系统地验证了联合训练 Inspector 与角色耦合奖励的作用。其主要不足在于统计稳健性报告、基线严格可比性、自动评估偏差以及多轮继续机制收益有限等方面。总体而言，该工作为多角色工具智能体的 RL 训练提供了一个结构清晰、可复用的框架，尤其“把停止/继续判断显式建模并纳入轨迹级奖励”的思路具有较好的迁移价值。
