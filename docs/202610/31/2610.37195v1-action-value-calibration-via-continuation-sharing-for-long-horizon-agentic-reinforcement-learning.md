## 摘要
长时程智能体的强化学习依赖于交互序列的反馈，这使得将信用分配给单个动作变得困难。现有方法（如 GiGPO）通过在共享状态比较动作来计算相对优势，但仅从单个采样延续估计每个动作的价值。由此得到的局部信用仍对轨迹后续决策敏感。为解决该问题，我们提出 ConCal（Continuation Calibration，延续校准），一种递归延续价值估计器，它利用 rollout 批次中已存在的延续证据。ConCal 根据进入的状态-动作-状态转移来匹配同一任务中的访问，将共享延续证据与每次访问自身的转移估计相结合，并反向传播校准后的价值以细化先前的动作价值估计。这降低了对单个采样延续的依赖，并在无需额外 rollout 的情况下缓解局部信用失真。留出回报诊断显示，与基于单个延续的估计相比，组内价值差异的误差更低，且与参考动作排序的一致性更高。在 Qwen2.5-1.5B-Instruct 上，ConCal 在 ALFWorld 和 WebShop 上分别将成功率较 GiGPO 提升 3.39 和 5.86 个百分点。代码见 https://github.com/Yingjian-Chen/ConCal。

## Abstract
Reinforcement learning for long-horizon agents relies on feedback from sequences of interactions, making credit assignment to individual actions difficult. Existing methods such as GiGPO compare actions at shared states to compute relative advantages, but estimate each action's value from a single sampled continuation. The resulting local credit remains sensitive to decisions made later in the trajectory. To address this problem, we propose ConCal (Continuation Calibration), a recursive continuation-value estimator that incorporates continuation evidence already present in a rollout batch. ConCal matches visits from the same task by their incoming state-action-state transitions, combines shared continuation evidence with each visit's own transition estimate, and propagates calibrated values backward to refine earlier action-value estimates. This reduces dependence on individual sampled continuations and mitigates local credit distortions without additional rollouts. Held-out return diagnostics show lower error in within-group value differences and higher agreement with reference action orderings than estimates based on individual continuations. With Qwen2.5-1.5B-Instruct, ConCal improves success rates over GiGPO by 3.39 and 5.86 percentage points on ALFWorld and WebShop, respectively. Our code is available at https://github.com/Yingjian-Chen/ConCal.

## 一、核心问题与研究动机

- **背景**：大语言模型智能体需要在长时程交互中完成多步任务（如网页导航、具身家务），强化学习依赖整条轨迹的最终反馈进行训练。如何把轨迹级反馈合理分配给单个动作（信用分配）是核心难题。
- **现有方法局限**：
  - GRPO 将同一轨迹级优势赋给所有动作，无法区分单步好坏。
  - GiGPO 在共享状态锚点处比较动作，实现局部比较；但每个动作的价值仍只来自**单条采样延续**（own sampled continuation）。
- **由此产生的问题**：
  - 低回报可能来自“好决策 + 后续失败”，高回报也可能掩盖早期错误决策。
  - 同一决策在不同轨迹中可能获得正负相反的局部信用，即“信用冲突”（图 2 显示冲突率在 WebShop 为 11.26%、ALFWorld 为 39.16%）。
- **核心洞察**：同一 rollout 批次中，同一任务下具有相同“前驱状态–动作–当前状态”转移的多次访问，天然共享后续延续证据；应利用这些跨轨迹证据校准动作价值，而非仅依赖单条延续。

## 二、方法论：ConCal（Continuation Calibration）

### 2.1 核心思想
- 递归地估计“延续价值”（continuation value），将**共享延续证据**与**每次访问自身的转移估计**部分融合，并沿轨迹反向传播，以校准早期动作价值。
- 不采集额外 rollout，仅复用现有批次中的跨轨迹结构。

### 2.2 关键技术细节

- **访问匹配（Matching Visits）**
  - 对访问 \((i,t)\) 定义匹配键 \(z_t^{(i)}=(x,s_{t-1}^{(i)},a_{t-1}^{(i)},s_t^{(i)})\)，即任务、前一状态、执行动作、当前状态。
  - 起始步用 START 标记替代前驱状态与动作。
  - 相同键的访问归入共享池 \(C(z)\)；匹配不要求处于相同时间步。

- **递归延续校准（Recursive Calibration）**
  - 初始化 \(\hat V_0(s_t^{(i)})=0\)，终止访问的后续价值为 0。
  - 第 \(b\) 层转移估计：\(Y_{t,b}^{(i)}=r_t^{(i)}+\gamma \hat V_{b-1}(s_{t+1}^{(i)})\)。
  - 池均值：\(\mu_b(z)=\frac{1}{|C(z)|}\sum_{(j,k)\in C(z)}Y_{k,b}^{(j)}\)。
  - 校准公式：\(\hat V_b(s_t^{(i)})=(1-\alpha_z)Y_{t,b}^{(i)}+\alpha_z\mu_b(z)\)，其中 \(\alpha_z=\frac{n_z}{n_z+1}\)，\(n_z\) 为池中不同轨迹数。
  - 性质：校准保持转移估计均值不变，并将访问间差异收缩为原来的 \(1/(n_z+1)\)，即保留各自偏离但削弱单条延续的噪声。
  - 递归执行 \(b=1,\dots,H\)，使后续校准价值逐步回传至更早决策。

- **动作价值与策略优化**
  - 动作价值：\(\tilde Q_t^{(i)}=r_t^{(i)}+\gamma \hat V_{H-t-1}(s_{t+1}^{(i)})\)，即“自身即时奖励 + 实际后继的校准延续价值”。
  - 步级优势：在状态组内中心化，并用**批量级共享尺度** \(\tilde d_B\) 归一化：\(\tilde A_t^{S,(i)}=(\tilde Q_t^{(i)}-\tilde Q_{S_t^{(i)}})/\tilde d_B\)。
  - 组合优势：\(\tilde A_t^{(i)}=A^{E,(i)}+\beta\tilde A_t^{S,(i)}\)。
  - 使用 PPO 式裁剪目标 + KL 正则优化策略，优势在优化期间固定。

## 六、主要结论与发现

- **性能提升**：
  - ALFWorld 总体成功率 **94.27%**，较 GiGPO 提升 **3.39 个百分点**，较 GRPO 提升 16.41 个百分点。
  - WebShop 任务分数 **90.18**、成功率 **79.69%**，较 GiGPO 分别提升 2.24 分和 **5.86 个百分点**。
  - 两个 benchmark 的汇总平均成功率均高于 GraphGPO。
- **价值估计质量**：
  - 组内中心化 MSE 较 Own-MC 在 ALFWorld 降低 **34.3%**，WebShop 降低 **16.8%**。
  - 动作排序一致性分别从 58.8%→61.2%、74.5%→81.8%。
  - Gap-matched 控制显示：MSE 下降很大程度来自偏好强度校准，而 ConCal 还额外改善排序。
- **消融结论**：
  - 所有共享延续证据的变体均优于 Own-MC；
  - 递归传播优于单次共享（Single-pass）；
  - 保留每次访问自身估计优于完全池化（Fully pooled）。
- **归一化发现**：group-wise 归一化会抹平价值差距带来的优势强度差异；batch-wise 归一化能保留校准后的偏好强度，因而被采用。
- **覆盖率与成本**：直接匹配覆盖 55.4%（ALFWorld）/43.4%（WebShop）的动作，递归传播扩展至 92.5%/67.5%；匹配与校准开销很小。
- **案例研究**：GiGPO 因“Select 5X”自身延续失败而赋予负优势、偏好重复点击；ConCal 借助共享延续证据反转偏好，给正确完成尺寸选择的动作正优势。

## 七、优点与亮点

- **方法简洁有效**：无需额外 rollout 或显式构建转移图，仅复用现有批次中的匹配访问，计算开销低。

- **递归反向传播**：使没有直接跨轨迹匹配的早期动作也能间接受益，显著扩大证据覆盖。
