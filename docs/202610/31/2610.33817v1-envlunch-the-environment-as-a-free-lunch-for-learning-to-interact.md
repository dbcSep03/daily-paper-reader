## 摘要
在智能体式数据分析中，语言模型智能体通常需要大量标注任务来学习如何与可执行环境（即数据库）有效交互。高质量标注任务需要大量人工投入，而可执行环境本身已提供丰富的交互结构和可验证结果。从这个意义上说，环境本身就提供了一份“免费午餐”，即一组无需人工标注的可验证任务。我们提出 EnvLunch，这是一个预热阶段，在下游智能体强化学习之前，将这种环境信号转化为智能体训练，而无需人工编写或模型生成的任务描述。EnvLunch 采样有效的动作轨迹，执行这些轨迹以获得最终观测，并训练智能体仅根据最终观测恢复一条功能等价的轨迹。这种无标签预热使模型在所有下游训练预算下平均超过基线 9 个百分点以上；并且在标签较少时，基线需要 8 到 32 倍的标注样本，才能达到 EnvLunch 模型在最小训练预算下所达到的准确率。仅让环境定义任务，比让模型在相同环境上自行编写任务带来更大的增益；这种预热还能改善在数据分析之外基准上的微调。因此，EnvLunch 节省了标注任务，并在此类任务有限时为微调智能体模型提供了更好的起点。

## Abstract
For agentic data analysis, language-model agents often require a large number of annotated tasks to learn how to interact effectively with executable environments (i.e., databases). While high-quality annotated tasks require heavy manual effort, an executable environment already provides rich interaction structure and verifiable outcomes. In this sense, the environment itself offers a free lunch, an additional set of verifiable tasks that require no human annotation. We propose EnvLunch, a warm-up stage that turns this environmental signal into agent training without human-written or model-generated task descriptions, before downstream agentic reinforcement learning. EnvLunch samples valid action trajectories, executes them to obtain final observations, and trains an agent to recover a functionally equivalent trajectory given only its final observation. This label-free warm-up enables the model to outperform the baseline by over 9 points on average across all downstream training budgets, and with few labels, the baseline needs 8 to 32 times as many annotated examples to match the accuracy that the EnvLunch model reaches at its smallest training budget. Letting the environment alone define the task yields a larger gain than having the model write its own tasks over the same environments, and this warm-up also improves fine-tuning on benchmarks beyond data analysis. EnvLunch therefore saves annotated tasks and provides a better starting point for fine-tuning agentic models when such tasks are limited.

- **背景**：在“智能体式数据分析”（agentic data analysis）中，语言模型智能体需要与数据库等可执行环境进行长程多轮交互，完成查询、分析与报告生成。当前训练此类智能体主要依赖两条路径：
  - 大规模**人工标注的可验证任务**做强化学习；
  - 从更大模型**蒸馏长程轨迹**。
  两者都需要大量人工投入与精细的数据 curation。
- **核心洞察**：可执行环境本身已包含丰富的状态/动作空间，执行结果天然可验证。因此，**环境本身就是一份“免费午餐”**——任何一条可执行轨迹都能定义成一个无需人工标注的可验证任务，执行结果就是答案。
- **研究问题**：现有方法（LLM 合成任务、模板生成任务）仍需把环境“翻译”成显式问题陈述。作者追问：**这一步是否必要？智能体能否直接从环境固有信息中学会有效交互？**
- **整体含义**：若成立，则可在下游 agentic RL 之前，用零标注的环境信号做一次轻量“预热”，显著降低对标注任务的依赖，并为微调提供更好的初始权重。

## 2. 方法论：EnvLunch

### 2.1 核心思想

- 在环境中**随机采样一条合法动作轨迹**并执行，得到最终观测；只把「环境 + 最终观测」交给智能体，要求它**恢复一条能产生该观测的功能等价轨迹**。
- 类比：在迷宫中随机放置一个目标点，训练智能体导航到它——目标不必对应有意义的用户问题，只要到达它需要有效交互即可。
- 监督信号是**执行结果**而非隐藏轨迹本身，因此无需问题、无需标签、完全可验证。

### 2.2 关键技术细节

- **动作池构建（Action Pool）**：
  - SQL 侧 15 个算子：10 个聚合类（从分组聚合到三表外键链、CTE 与自身均值比较），5 个非聚合类（过滤下投影、带 tie-break 的 top-k 等）。
  - pandas 侧：1 个源动作（单表或外键合并两表）+ 0/1–2/3–4/5–6 个变换链（过滤、top-k、分组聚合、列比值/排名）+ 1 个终端动作（标量聚合、分位数、行数）；最高两级以 1/2 概率加 join。
  - 算子是通用接口，适用于任意关系数据库，无需逐环境设计；参数从当前观测动态实例化（阈值取列的真实分位数、类别过滤取列中实际存在的值）。
- **轨迹合成（式 1–3）**：
  - τ = (a₁,…,a_L)，其中 a_ℓ ∈ A(o_{ℓ−1})，o_ℓ = a_ℓ(o_{ℓ−1})；逐步执行得到目标观测 o⋆ = o_L = τ(E)。
  - 预热任务定义为 T(E, τ) = (E, o⋆)，隐藏 τ。
  - 目标是找到 τ̂ ∈ [τ]_E = {τ′ : τ′(E) = o⋆}，即**功能等价类**而非原始动作序列（轨迹到观测是多对一映射）。
  - 注：恢复一条长度 L=5 的合成轨迹，往往需要远多于 L 轮的试错与推理（案例中用了 14 个动作）。
- **在线合成与过滤**：
  - 每追加一个动作就执行部分轨迹、重建候选池 A(o_ℓ)，仅保留操作数存在且仍能改变观测的动作（如剩余行数很少时移除 top-k）。
  - 轨迹须在每个扰动副本中可执行且结果非退化，并至少在一個副本中结果发生变化，以排除“直接复制目标观测”的退化解。
- **反事实多环境验证（防 reward hacking）**：
  - 对原数据库构造 K 个智能体不可见的“what-if”副本：删除每张 ≥20 行表的 30% 行并沿外键级联保证参照完整性；dataframe 侧额外对度量列乘随机缩放因子，标识/键列不变。SQL 用 K=2，pandas 用 K=3。
  - 奖励：R(τ̂; τ, E′_{1:K}) = (1 + w(1 − t/t_max)) · min_{1≤k≤K} m(τ̂(E′_k), τ(E′_k))，其中 m∈[0,1] 为执行结果一致度（关系结果为行多重集重叠，dataframe 为规范化后精确比较），t 为交互轮数，t_max 为 16（SQL）/48（pandas），w=0.5 为简洁性奖励权重。
  - 前置因子奖励简短轨迹；min 要求在所有副本上一致，等价于把等价类替换为各副本交集。
  - 消融证据：无副本时智能体 hack 奖励、停止查询、全部退化为硬编码常量，208 个留出预热任务准确率降至 16.8（低于未训练 28.1，有副本为 46.1）。
- **优化**：目标为最大化期望奖励（式 6），用标准 **GRPO** 优化（8 rollouts/task、全参数更新、lr 1e-6、KL 系数 0.01、熵系数 0.001 等）。
- **下游阶段**：预热后的 checkpoint 再在带标注的下游任务上做常规 agentic RL（同一 GRPO 设置）。

## 6. 主要结论与发现

- **主结果**：6 个数据分析基准上，跨所有训练预算平均提升 **+9.32（9B）/ +9.63（4B）**；逐项增益 3.8–14.3 分。
- **标签效率**：每个曲线上，基线需 **8–32 倍**（中位 16×）标注样本才能追平 EnvLunch 在最小预算下的精度；DSEval 两条曲线基线在评测范围内**从未**达标。
- **极端低标签**：仅 1 个标注样本训练 32 步，EnvLunch 仍领先 **5.5%–12.6%**，且每一步、每一难度分位均为正。
- **跨域迁移**：7 个非数据分析基准平均 **+5.48（9B）/ +3.73（4B）**；HotpotQA 提升最大（+15.3/+14.0），BIRD 匹配预算达 64×；但 SpreadsheetBench 4B 为 **−0.2**，AppWorld 4B 仅 +0.4。
- **环境定义任务优于模型自写任务**：三种自合成范式在 4B 为 +5.2/+5.3/+6.4、9B 为 +1.6/−0.3/−4.0，均低于 EnvLunch 的 +9.6/+9.3；作者归因于自标注缺乏“标签是否回答了所写问题”的校验。
- **机制证据**：
  - 预热后模型更常显式推理、先检查数据结构、分层缩小搜索空间、出错后重写查询；基线更常重复已试动作或重复确认已读值。
  - 在可控环境中，EnvLunch 降低环境不确定性最显著，且该差异不能由“动作更多”解释（4B 下与拒绝采样微调动作数相近但不确定性下降差异明显）。
-

- 在 6 个可控领域中，EnvLunch 均更快将剩余不确定性从 6 bit 降至 0 bit；4B 下其动作数与拒绝采样微调相近，但不确定性下降更明显，说明增益来自更具信息量的查询选择，而非单纯增加交互轮数。
  - 定性行为上，预热模型更常先检查数据结构/分布、分层缩小候选空间，并在失败后改写查询；基线更常重复已试动作或重复确认已读值。作者据此将机制概括为：模型学会了把环境视为“可验证的搜索空间”，而非依赖问题陈述进行模式匹配。

## 8. 总体评价与启示

- **方法价值**：EnvLunch 的核心贡献不是提出更复杂的任务生成器，而是把“任务定义”从自然语言问题转为“可执行环境 + 目标观测”，用功能等价类替代轨迹模仿。这一视角简洁、通用，且天然适配可验证奖励，为 agentic RL 的冷启动提供了一条低标注成本路径。
- **实验严谨性**：同数据、同顺序、同种子、同解码与同 scorer、仅初始权重不同的配对设计，是本文最有说服力的部分；对继续预训练、拒绝采样微调、自写任务、自由探索、自博弈等替代解释的对照，以及对 reward hacking 的反事实消融，显著增强了结论可信度。
- **结论边界**：结果支持“环境固有信号可作为下游 agentic RL 的有效预热”，但应理解为**改善初始权重与标签效率**，而非替代下游带标注训练；其收益在中等规模 Qwen 模型与现有 benchmark 上成立，向更大模型、更复杂真实环境和更长程任务的外推仍需验证。
- **实践启示**：
  - 对拥有可执行数据库/代码环境的团队，可优先构建“随机合法轨迹—目标观测—功能等价恢复”的预热任务，以较低标注成本获得 RL 初始权重；
  - 奖励设计应加入多副本反事实一致性约束，防止模型通过复制目标观测、硬编码常量或提前停止来 hack；
  - 任务构造应保证环境与评测集不相交，并监控负迁移与动作空间失配；
  - “免费午餐”的准确含义是节省人工标注与问题编写，而非零算力；实际部署需权衡预热时间、副本构造开销与下游预算。
