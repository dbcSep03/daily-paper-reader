## 摘要
递归自我改进（RSI）要求一个智能体系统能够设计、训练并评估其自身的后继系统。数据驱动的后训练是该循环的核心部分，但现有评估仅在单一基准上衡量它：智能体从静态池中选择数据，或蒸馏一个更强的模型，以在一次运行中推高一个分数。真实的后训练是多领域的，一个领域的收益必须与另一个领域的回退进行权衡。我们提出 ParetoRSI-Gym，其中智能体搜索数据、筛选数据、训练、读回各领域结果并重复这一过程，而除数据外的一切均保持不变：初始 LLM、五个领域（数学、代码、金融、医学、科学）、工具集以及 SFT 流水线。每个领域的泛化基准将能力提升与对智能体所优化分数的过拟合区分开来。在三个智能体系统、三个基础模型、五轮和多个随机种子下，最强的系统 Claude Code 搭配 Opus-5 将其代理最优检查点的泛化分数相对于起始模型提高了 9.2%（+2.3 绝对点），该结果在三个基础模型和五个领域上等权平均，单领域相对增益最高达 63%（Ministral-3-3B 上的医学领域）。进一步分析表明，harness 与其所驱动的模型同样重要，并且每个智能体都保持独特的数据选择策略。我们将自己的工作视为迈向在真实机器学习工程中评估 RSI 系统的一步。

## Abstract
Recursive self-improvement (RSI) requires an agentic system to design, train, and evaluate its own successor. Data-driven post-training is a central part of that loop, yet existing evaluations measure it on a single benchmark, where an agent selects from a static pool or distills a stronger model to push one score up in one run. Real post-training is multi-domain, and a gain in one domain has to be weighed against a regression in another. We propose ParetoRSI-Gym, in which an agent searches for data, curates it, trains, reads back per-domain results, and repeats, with everything but the data held fixed: the initial LLM, the five domains (math, code, finance, medicine, science), the toolset, and the SFT pipeline. Generalization benchmarks in each domain separate capability gains from overfitting to the scores the agent optimizes against. Across three agent systems, three base models, five rounds and multiple seeds, the strongest system, Claude Code with Opus-5, raises the generalization scores of its proxy-best checkpoint by 9.2% relative to the starting model (+2.3 absolute points), averaged with equal weight over three base models and five domains, with a single-domain relative gain of up to 63% (medicine on Ministral-3-3B). Further analysis shows that the harness matters as much as the model it drives, and that each agent keeps a unique data selection strategy. We see our work as a step towards evaluation of RSI systems in real-world machine learning engineering.

## 2. 方法论：ParetoRSI-Gym

### 2.1 核心思想
构建一个**循环式数据策划环境**：除数据外一切固定（初始 LLM、五个领域、工具集、SFT 流水线），智能体反复执行"搜索数据 → 筛选 → 训练 → 读回分领域结果 → 修订原则"，目标是推进能力向量的 **Pareto 前沿**，而非抬高任一单坐标。

### 2.2 五条设计原则
| 原则 | 含义 |
|---|---|
| 跨轮状态 | 模型池 M、数据池 P、书面原则 R 跨轮持久，第 t 轮的提交约束第 t+1 轮 |
| 动态数据源 | 数据在运行时从 HuggingFace Hub 实时搜索、拉取，而非预置池 |
| 反馈驱动修订 | 每轮返回分领域代理分数**及逐题评估轨迹**，智能体据此重写原则 |
| 多领域目标 | 同时策划 N=5 个领域，每轮看到完整分数向量与非支配检查点集合 |
| 泛化评估 | 最终分数来自智能体从未见过的留出基准，区分真实能力增益与对反馈的过拟合 |

### 2.3 算法流程（文字版）
1. 初始化：模型池 M={M₀}，数据池 P=∅，初始能力向量 s₀=T_proxy(M₀)，智能体据 s₀ 与预算 β₀ 写出初始原则 R₀。
2. 每轮 t=1…T：
   - **ACQUIRE**：依据 R_{t−1} 通过 SEARCH（关键词/标签检索）、SELECT（选数据集与子集）、PULL（下载并检查条目）扩充数据池 P。
   - **COMMIT**：从模型池中选择父检查点 M_par，确定训练集 D_t 与训练配置 C_t（在预算 β 内）。
   - **训练**：M_t = S(M_par, D_t; C_t)，加入模型池。
   - **评分**：s_t, E_t = T_proxy(M_t)，返回分领域分数与逐题结果。
   - **修订**：R_t = A(R_{t−1}, s_{0:t}, E_t)，在固定预算内重写原则。
3. 结束后在泛化基准 T_general 上分别报告**最终轮模型**与**代理最优（proxy-best）检查点**。

### 2.4 关键技术细节
- **训练固定为 LoRA SFT + AdamW**，单轮 1 个 epoch；智能体只能在固定范围内选 lr、LoRA rank、batch size、序列长度、warmup，其余流水线冻结。
- **预算约束**：每轮上限 1500 万训练 token、4 万条目；一次运行 5 轮；每轮约 30 分钟、3 美元模型预算。
- **防污染机制**：所有候选条目需通过针对代理与泛化题目的 **13-gram 去污染**检查；含代理文本的搜索被记为违规；金标答案永不可见。
- **训练沿谱系累积**：从某检查点继续训练会继承其祖先的全部学习（含损害），只能通过回退到更早检查点"撤销"。
- **原则文件（SKILL.md）**：8000 token 预算，每条信念须标注证据（如 `r2:finance+6.3`），由 harness 校验数值真实性，虚假引用会被拒绝。

## 6. 主要结论与发现

- **智能体确有增益但差异巨大**：代理最优检查点相对 M₀ 的平均增益为 Claude Code **+2.3 点（相对 +9.2%）**、Codex **+0.6（+3.1%）**、CheetahClaw **−0.3（+2.9%，相对值受低基线放大）**。
- **增益分布不均**：医学（+4.3）与代码（+3.2）提升最明显，**数学普遍下降**；最大相对增益 +63%（Ministral 医学），但部分源于模型学会了输出选项字母的格式而非医学知识。
- **模型依赖性强**：Ministral-3-3B 上增益最大，Qwen 与 Olmo 上较小。
- **智能体"先达峰后回落"**：9 个配置中 **7 个的代理最优轮不是最后一轮**；45 个模型–领域单元中 24 个在后续轮次出现相对最优代理轮的性能下降。
- **单一检查点难以覆盖五领域**：43/45 单元中某领域的最佳轮并非智能体所选轮，平均代价 2.0 点、最高 6.9 点——说明当前系统缺乏"在探索新能力的同时守住已有能力"的 Pareto 推进能力。
- **Harness 与模型同等重要**：固定骨干下，Codex 平均 +4.3、Claude Code +2.6、CheetahClaw +0.2；代码领域 Codex 单项高达 +13.2。
- **智能体有固化数据偏好**：同一智能体不同运行的 Jaccard 为 0.24，不同智能体仅 0.07；共享基模型也不提高重叠（0.23 vs 0.25），说明选择策略由智能体自身决定、不随目标模型自适应。
- **探索随轮次衰减**：后期轮次首次进入数据池的新数据集越来越少；**50 轮中有 49 轮智能体未打开任何一行数据**（full_row_views = 0）就决定了数万条目的去留。
- **人类仍占优**：人类监督在每个基模型上平均匹配或超过最强智能体，数学与金融上尤为明显。

## 8. 局限性与潜在问题

### 8.1 评测层面的局限
- **代理基准题量过小**：150–200 题的规模使单题权重达 0.5–0.7 点，与报告的标准差（1–3 点）同量级；智能体在 5 轮内可观测到数十次分数反馈，存在对代理集"软过拟合"的风险，而论文仅以泛化基准的最终分数作为隔离手段，未量化智能体策略与代理分数波动之间的相关性。
- **泛化基准的"同能力不同题"假设**：MATH500 ID/OOD、GPQA ID/OOD 等划分依赖题目层面的去污染，但同一能力维度的 ID 与 OOD 难度分布是否可比未做报告；若 OOD 更难，则"泛化增益小于代理增益"可能部分来自难度差异而非过拟合。
- **代码领域代理/泛化不同源**：MBPP+ 与 HumanEval+ 是不同基准而非同基准划分，与其他四领域的设置不一致，跨领域比较时需谨慎。
- **"Domain Best" 为不可部署的 oracle 行**：该行需要事后知道每个领域的最佳轮次，只能作为诊断上界；论文将其与 Final、Proxy Best 并列展示，读者容易误读为可达性能。

### 8.2 实验设计层面的局限
- **配置数量与重复不均衡**：9 个配置中仅 6 个（Claude Code、Codex × 3 基模型）有 3 种子重复，CheetahClaw 全部为单次运行；在标准差可达 5–7 点的前提下，单次运行的结论稳定性存疑，而论文仍将其纳入平均增益统计。
- **Harness 消融的混淆**：消融固定骨干为 DeepSeek V4.1 Flash Max，但主实验中的 CheetahClaw 配置使用 deepseek-v4-flash，二者命名与版本关系需读者自行推断；harness 差异（工具集、上下文管理、循环控制）未被分解为具体组件，因此"harness 与模型同等重要"的结论只能定位到系统级，无法指导后续改进。
- **人类基线强度有限**：人类基线为单点对照、未报告重复次数与操作者背景，且人类只接管"提交"步骤、搜索仍由智能体完成，因此它衡量的是"人类判断 + 智能体检索"的混合系统，而非纯人类上限。
- **预算与时间约束可能压制探索**：每轮 30 分钟、3 美元、5 轮的总预算对"发现新数据源"这一高成本动作不友好，观察到的"探索随轮次衰减"可能部分是预算压力而非策略缺陷所致；论文未做预算敏感性分析。

### 8.3 方法与可复现性局限
- **算力信息缺失**：未报告 GPU 型号、数量与总训练时长，仅给出 token 与条目上限；LoRA SFT 的实际吞吐、排队时间与总成本无法估算，第三方复现存在门槛。
- **训练流水线完全冻结**：仅开放 lr、LoRA rank、batch size、序列长度、warmup 五个超参，智能体无法改变数据格式、loss 掩码、课程顺序等对 SFT 效果影响很大的因素，这可能低估了"自我改进"的潜力，也使结论更偏向"数据策划"而非"完整后训练"。
- **原则文件的可验证性边界**：harness 校验证据中的数值真实性，但无法校验"因果归因"是否正确（例如把提升归因于某数据集，实际可能来自 lr 变化）；因此 SKILL.md 的可审计性只到"引用不造假"，未到"推理正确"。
- **未打开数据行即决策**：49/50 轮 full_row_views=0 说明智能体主要依赖数据集卡片与元数据做判断，这一行为本身是有价值的发现，但论文未进一步分析"若强制抽样查看若干行"是否能改善选择质量，缺少针对性干预实验。

## 9. 启示与未来方向

- **对 RSI 评测设计的启示**：单分数基准已不足以区分智能体能力，"多领域 Pareto 推进 + 留出泛化 + 跨轮状态"应成为数据策划类基准的默认配置；同时需要引入**回退成本**指标（守住已有能力所需的代价），以刻画"探索—巩固"平衡。
- **对智能体系统的启示**：harness 差异带来的增益（Codex +4.3 vs CheetahClaw +0.2）与基模型差异同量级，说明当前瓶颈更多在**工具编排、上下文管理与反馈利用**，而非底层模型能力；"先达峰后回落"与"探索衰减"指向两个具体改进点——显式的经验回放/回退机制，以及强制性的数据抽样检查环节。
- **对数据策划策略的启示**：Jaccard 分析（同智能体 0.24、跨智能体 0.07）表明智能体形成了高度个体化的数据偏好且不随目标模型自适应，未来可研究**以目标模型诊断为条件的数据选择**（如依据逐题错误类型定向检索）。
- **可延伸的实验**：(1) 增大代理基准题量或采用多次子采样平均以降低方差；(2) 预算敏感性曲线；(3) 强制数据行查看的消融；(4) 将训练超参纳入智能体动作空间；(5) 多人类操作者重复以建立可靠人类上界。

## 10. 总体评价

论文提出了一个设计严谨、约束清晰的多领域数据策划环境，其核心贡献不在于证明"智能体能自我改进"，而在于**用可审计的实验揭示了当前智能体在 Pareto 推进上的系统性缺陷**：增益真实但有限（平均 +0.6 至 +2.3 点）、分布高度不均（医学/代码获益、数学退化）、且普遍无法在探索新能力的同时守住旧能力。代理/泛化双轨、13-gram 去污染、跨轮持久状态与证据强制标注构成了可信的评测骨架；harness 消融、人类基线与 Jaccard 分析提供了有价值的归因线索。

主要短板在于统计功效与可复现信息：小代理集、不均衡的种子重复、缺失的算力报告，以及未分解的 harness 差异，使得部分结论（尤其是 CheetahClaw 的负增益与 harness 排序）只能视为初步信号。总体而言，这是一篇**问题设定有价值、实验诚实、结论需在更大规模上复核**的工作，适合作为多领域 RSI 评测的起点性基准，而非终局性结论。
